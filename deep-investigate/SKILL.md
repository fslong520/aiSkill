# 深入研究

研究围绕用户需要回答的问题和采取的行动展开，兼顾发现未知的解释与论证当前答案，不以轮数、来源数量或发现数量衡量完成度。用户要求全面梳理概念、来源或研究现状时，覆盖本身就是交付要求，不能因已有一个可用建议而提前结束。

## 确定问题与复用知识

- 明确要回答的问题、结论将用于什么决策，以及什么证据足以支持交付。已有上下文足够时直接推进，不强制进行一轮确认。
- 先查找项目已有研究及相关设计，核对结论的前提、版本和适用范围。复用仍成立的部分，只调查新问题、变化的条件和影响判断的缺口；旧结论失效时记录原因和替代结论。
- 在已有主题文档维护当前答案，暂定结论明确标注。尚无答案时写出候选解释和关键未知；同时记录概念、解释路径与来源类别的覆盖范围，不能只积累支持当前答案的材料。
- 普通调试按复现、提出竞争假设、区分假设的实验、修复、回归推进。若遇到无法据现有代码或实验判断的机制问题，只把这个明确的未知抽出研究，再将结论带回修复流程。

开始记录和交付时读取[知识组织与格式](references/templates.md)，沿用现有主题和文件，不为每轮或每次对话重建资料。

## 展开探索与收敛论证

研究初期探索问题的不同表述、相关概念、竞争解释和独立来源，允许调查尚不明确用途的线索。检查不同术语、原始概念出处、相反观点和跨领域解释，核对概念的原始定义、假设及后续用法的变化，避免始终沿用同一组关键词、引用链或理论框架。

形成候选答案后，围绕影响结论的未知集中推导和实验；遇到无法解释的现象、矛盾依据或新的概念框架时，重新扩大探索范围。尚不能判断相关性的线索先做有限探索，再决定是否深入；已确认与交付无关的支线只记录。接续研究沿用已有覆盖记录，补查遗漏与变化，不机械重走全部探索。

## 按命题选择方法

| 要判断的内容 | 核心依据 |
| --- | --- |
| 逻辑或数学命题 | 写明定义、假设和推导，尝试构造反例；需要一般性保证时给出证明，适用时使用形式化工具 |
| 程序行为 | 沿真实源码路径追踪状态与控制流，用可复现实验检验关键假设，注明版本、输入及环境 |
| 经验事实或性能 | 检查原始数据、测量方法、样本和适用条件；比较时控制会影响结论的变量 |
| 方案建议 | 将已支持的事实和推论连接到用户目标，说明取舍及哪些条件变化会改变建议 |

权威或原始来源提供的是待审查的论据，不能代替推理。检查来源的假设、方法和原文是否支持当前主张；多个转述同一材料的来源不算独立证据，单个来源也不自动无效。实验样例不能证明普遍命题，代码中存在一条路径也不证明实际执行经过它。来源与实验冲突时定位条件或推理上的差异，不按来源名气或数量裁决。

## 研究与独立复核循环

1. 主 agent 按能独立求解的问题或命题派发研究任务，也可分配竞争解释、陌生概念及其出处的探索。提供用户目标、已有结论及条件、覆盖范围、关键未知和原始材料入口。无独立子问题时直接研究，不强拆资料搜集任务；可独立推进的问题并行处理。
2. 收到结果后更新当前答案，合并重复论据，处理矛盾。正文完整表达研究对象、条件、判断和对需求的意义，链接只补充依据；禁止用“发现 12 已验证”“见上一轮”替代结论内容。
3. 由未参与该结论形成的 agent 独立复核：是否回答用户问题、核心推理是否成立，并从原始问题出发检查遗漏的概念、竞争解释和来源类别。给复核者完整问题、当前结论、覆盖范围和原始依据；不能只沿研究者的关键词和引用链检查。
4. 复核发现决定性缺口时，主 agent 继续安排针对性调查，更新答案后再次复核；收到缺口报告不等于任务结束。复核通过即交付，不要求最低轮数、每轮新建 agent 或穷尽所有支线。

派发研究和复核时读取[任务提示词](references/prompts.md)。大型项目的整体任务、依赖和开发验收组织使用 `docs-sprint` 技能，本技能负责其中的研究问题。

完成研究需要同时满足：与用户问题相关的重要解释和来源类别已得到合理探索，关键结论有充分依据，独立复核未发现影响交付的重大遗漏。不能仅因当前答案获得支持或连续搜索没有新结果，就认定探索充分；应检查搜索方式是否过于单一。明确未覆盖的部分，不宣称穷尽全网。

用户设定的范围与时间限制优先；若关键材料、权限或外部条件确实无法取得，说明当前可支持的答案、无法判断的部分及需要的条件，不能标为研究完成。先推进不依赖缺失条件的部分；若无法使用独立 agent，明确未完成独立复核，不把自查写成独立通过。

## 交付

正文先给当前结论、建议及适用条件，再给决定性推理和仍影响决策的未知。详细推导、原始材料和复现记录按需留在支撑文档，避免把研究过程流水账作为交付物。

交付前做消融检查：移除重复举证、无关支线和仅用于组织过程的编号或文档层级；删减后仍须能理解结论、检查关键推理并继续研究。

回复和交付语言沿用用户或项目约定。研究材料的位置从当前工作目录解析，不从技能安装目录解析。
