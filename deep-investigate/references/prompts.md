# 任务提示词

按实际任务填写以下上下文，可直接提供文档路径与确定的代码版本；关键问题和已知结论要写全，不能仅给编号或要求子 agent 猜测上文。只有影响任务的内容才进入提示词。

## 研究任务

```text
用户要解决的问题及结论用途：{问题、决策或交付要求}
本任务要回答的子问题：{待检验命题，或需要探索的概念、竞争解释及其出处}
已有知识：{可复用结论、适用条件、证据入口；存在的冲突或未知}
已有覆盖：{已探索的概念、解释路径和来源类别；尚未覆盖的部分}
调查依据：{原始材料、代码路径与版本、实验环境}
本次范围与约束：{边界、可操作资源、用户给定的限制}
结果写入：{现有主题下的指定文件；并行任务不同时写同一文件}

探索任务允许调查尚不明确用途的线索，检查不同术语、概念原始定义和独立解释。
论证任务选择适合命题的推导或实验方法，集中解决影响结论的未知；出现矛盾或新框架时重新展开探索。
返回可独立阅读的答案：对象、条件、判断、对用户问题的意义，以及关键推理和依据。
区分实际观察、推导和仍待检验的假设；说明证据能支持到什么范围。
说明新增的概念或解释、覆盖缺口及下一步要区分什么；尚不明确相关性的线索先有限探索，已确认无关的支线不继续展开。
```

## 独立复核

```text
用户问题与完成条件：{原始需求、结论用途、范围}
当前答案：{完整判断、建议、适用条件}
覆盖范围：{已探索的概念、解释路径和来源类别；尚未覆盖的部分}
复核材料：{当前研究文档、原始材料、关键推导、可复现实验及代码版本}

检查答案是否满足需求，重点审查决定建议的推理链。
从原始材料、推导或必要实验核对关键主张，寻找能推翻它的反例和条件差异。
从用户原始问题出发，独立检查遗漏的概念、竞争解释和来源类别，不能只沿已有关键词与引用链复核。
说明遗漏如何可能改变答案或影响用户要求的覆盖；尚不能判断时做有限探索，不凭没有新搜索结果认定覆盖充分。
不要以来源数量、材料篇幅或轮数判定质量，也不要求穷尽无关问题。
返回：
- 通过，或需要补充调查。
- 每个决定性问题的完整描述：哪项判断在什么条件下不成立或缺少支持，
  依据是什么、为何影响答案或覆盖要求，以及什么证据能区分剩余解释。
- 已确认不影响答案及覆盖要求的后续问题单列，不作为阻止交付的理由。
不要只返回发现编号、引用链接或前轮结论。
```

主 agent 根据复核结果确定后续任务。修正后给复核者更新后的完整结论和改变的依据；复核范围聚焦改动及其影响，不重复无变化的全部研究。
