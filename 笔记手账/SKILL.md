# 笔记手账 - 教育知识卡片Prompt生成器

## 这个技能是做什么的？

**一句话**：输入知识点/主题，输出符合"笔记手账"风格的AI绘图Prompt。

**适用场景**：
- CSP-J/CSP-S/GESP 教学知识卡片
- 每日打卡海报
- 知识点讲解配图
- 学习计划/总结可视化

## 文档结构

本技能按模块拆分，主流程在本文件，细节见各附属文件：

| 文件                   | 内容                                                           |
| ---------------------- | -------------------------------------------------------------- |
| **SKILL.md**（本文件） | 主流程：简介、执行流程、Principles、AVOID                      |
| **styles.md**          | 风格体系：视觉DNA、9套风格定义、内容模块、手写体规范、风格速查 |
| **templates.md**       | 布局规范、输出框架、四个可直接复制的Prompt模板                 |
| **oi-code-style.md**   | 含代码知识卡的OI竞赛代码风格规范                               |
| **reference.md**       | 墨蓝手账配色系统（含RGB）、装饰元素库、质量检查表              |
| **examples.md**        | 完整Prompt示例（墨蓝手账默认配色）                             |
| **CHANGELOG.md**       | 版本变更日志                                                   |

生成流程：**读本文件执行流程 → 按所选风格取 styles.md 色值与装饰 → 按页面类型取 templates.md 布局与模板**。

## 执行流程

### 步骤1：理解需求

确认以下信息（如用户已提供则跳过）：
- 封面页标题？（如："STL容器：C++的工具箱"，必填）
- 封面副标题？（如："CSP-J初赛必会知识点"，可选）
- 知识点主题？（如：栈和队列、二叉树遍历、排序算法，用于知识页标题）
- 用途？（知识卡片 / 打卡海报 / 讲解配图）
- 页数？（单页 / 多页系列）
- 风格主题？（默认墨蓝手账：墨蓝主调暖金点睛，齐整而有层次、暖意从容，适合12岁以上正式教学；低年级孩子建议选活力手账：亮色活泼，亲和力强。全套风格定义见 styles.md——经典 / 科幻 / 青绿新生 / 蔚蓝格调 / 二次元/动漫 / 少女粉 / 我的世界像素风）
- 特殊要求？（需包含代码？需对比？需图解？）

**标题为必填项**，其余可省略由AI自动补全。用户未提供标题时，须主动询问不可跳过。

### 步骤2：内容规划

根据主题规划内容结构：

```
封面页（可选）
├── 标题
├── 副标题/主题词
└── 装饰元素

知识页
├── 分区标题（一、二、三...）
├── 各分区内容（卡片式）
├── 高频易错点
└── 一句话记忆

练习页（可选）
├── 题目列表
└── 解答区
```

（可选：知识页可用"论证驱动分区"布局——每论证步一卡片区块，见 styles.md「论证驱动分区」节。）

### 步骤3：填充维度

按以下维度生成Prompt（优雅简洁风格）。以下为**默认墨蓝手账风格**之维度，其他风格按 styles.md 色值与字体替换。

#### 封面页维度

| 维度            | 内容                                               |
| --------------- | -------------------------------------------------- |
| **layout**      | 居中构图，留白充足，简洁优雅                       |
| **title**       | 墨蓝瘦金体（加粗）手写，居中，柠檬黄细下划线+暖金细双线，标题两侧对称暖金小星 |
| **subtitle**    | 黛蓝瘦金体（加粗）手写，居中，细柠檬黄下划线       |
| **frame**       | 双线内框（暖金外线+黛蓝内线），四角暖金星簇，顶底暖金细分隔线，框缘稀疏柠檬黄/黛蓝小星 |
| **decorations** | 墨蓝标签（左上），柠檬黄便利贴（右上）+编号小标签（下），角落暖金/柠檬黄星簇，底部三枚主题图标卡片（雪白底暖金细边+小字标注），页脚暖金双图标 |
| **background**  | 暖奶油色纸张纹理，轻微阴影                         |

#### 知识页维度

| 维度                 | 内容                                                                           |
| -------------------- | ------------------------------------------------------------------------------ |
| **section_header**   | 墨蓝瘦金体标签，**摆正不倾斜**，**中等字号**，加粗                             |
| **content_card**     | 白色卡片，轻微阴影，顶部**双色条**（主色条+暖金细线）                          |
| **icon_style**       | 手绘简笔画，黛蓝/雾蓝，简洁克制                                                |
| **text_hierarchy**   | 标题大而醒目 → 正文小 → 重点荧光笔高亮，层级清晰                               |
| **body_text**        | 瘦金体，**加粗（BOLD）**，**字号偏小**，粗线                                   |
| **special_sections** | 高频易错点（暖金荧光笔高亮）+ 一句话记忆（柠檬黄高亮底），底部并列，**小字号** |

#### 练习题页维度

| 维度         | 内容                                           |
| ------------ | ---------------------------------------------- |
| **layout**   | 双栏等宽，网格对齐                             |
| **question** | 墨蓝手绘编号圆圈 + 题目文字，**中等字号**      |
| **options**  | 2×2网格排列（A B / C D），对齐精确，**小字号** |
| **spacing**  | 题目间等距，选项间等距                         |
| **footer**   | 提示语居中，青碧箭头，**小字号**               |

### 步骤4：输出

按页面类型（封面页 / 知识页 / 练习题页 / 答案解析页）取用 **templates.md** 中对应输出框架与可复制模板，色值按所选风格取自 **styles.md**，含代码时按 **oi-code-style.md** 格式化。

## Principles

| 原则     | 说明                                               |
| -------- | -------------------------------------------------- |
| 优雅简洁 | 留白充足，元素克制，不杂乱                         |
| 风格一致 | 同系列图保持配色、布局、装饰元素统一               |
| 清晰优先 | 信息层级分明，标题→正文→重点一目了然               |
| 对齐精确 | 双栏等宽，选项网格对齐，间距均匀                   |
| 适龄匹配 | 面向12岁学生，活泼但不幼稚，专业但不枯燥           |
| 中文优先 | 所有文字内容默认中文                               |
| 不加日期 | 除非用户明确要求，否则不出现 Day XX、日期等序列标记；便利贴只写页码（如"第1页"） |
| 代码规范 | 含C++代码时需使用OI竞赛风格（见 oi-code-style.md） |

---

## AVOID

- 避免装饰过多导致杂乱
- 避免元素倾斜错乱（默认风格下标签/便利贴/卡片一律摆正不倾斜，装饰适度：标签/便利贴/角落小星/页脚图标/细分隔线，忌堆砌成杂乱）
- 避免元素拥挤，留白不足
- 避免对齐不精确，间距不均
- 避免风格突变（同系列保持一致）
- 避免擅自添加 Day XX、日期等序列标记（除非用户明确要求；便利贴只写页码）
- 避免使用"我有个朋友"、"众所周知"等AI痕迹表达
