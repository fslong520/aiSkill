# 笔记手账 - 参考文档

## 风格定义

### 视觉DNA

**核心美学**：模拟真实笔记本/手账的质感，营造"学习笔记"的亲切感。**默认墨蓝手账风格**——墨蓝主调，暖金点睛，优雅规整，文气从容。

| 元素 | 特征 | 技术关键词 |
|------|------|-----------|
| **基底** | 暖奶油色纸张，撕纸边缘，活页孔 | cream_paper, torn_edge, hole_punches |
| **装订** | 螺旋装订（底部或左侧） | spiral_binding |
| **配色** | 墨蓝 + 黛蓝 + 雾蓝 + 青碧 + 暖金 + 柠檬黄 | ink_blue, indigo, mist_blue, teal, warm_gold, lemon_yellow |
| **装饰** | 克制而丰富：标签、便利贴、角落小星、页脚图标、细分隔线——全部摆正不倾斜，禁止涂鸦/气泡框/波浪线 | straight_tags, sticky_notes, stars, gold_separators, footer_icon, no_tilting |
| **字体** | 瘦金体加粗（BOLD），笔画瘦劲锋利、锋芒劲挺 | slender_gold_script, bold |
| **卡片** | 白色圆角卡片，浅灰阴影，顶部色条 | white_card, rounded_corners, shadow, color_bar |

### 装饰元素库

#### 固定装饰（克制而丰富）
- **标签**：墨蓝，固定在左上角，摆正不倾斜
- **便利贴**：柠檬黄，右上角，手写标语，摆正不倾斜；其下可加编号小标签（如"第X单元"）
- **双线内框**：封面页专属——暖金外线 + 黛蓝内线，留足边距；四角暖金星簇（每角2-3颗，对称），顶底暖金细分隔线，框缘稀疏柠檬黄/黛蓝小星
- **星星☆**：暖金和柠檬黄（少量黛蓝），散落在角落，克制
- **下划线**：柠檬黄直线（非波浪线），标题下，可配暖金细双线；标题两侧可加对称暖金小星
- **高亮**：柠檬黄划痕或暖金浅底，标重点词
- **双色条**：卡片顶部主色条（黛蓝/雾蓝/青碧交替）+ 暖金细线
- **分隔线**：内容间暖金细分隔线
- **主题图标卡片**：封面页底部三枚，雪白底 + 暖金细边 + 小字标注，等距排列
- **页脚图标**：铅笔✎/灯泡💡/书本📖，暖金，居右下角，每页一枚；封面可双图标（右下铅笔+左下书本）

#### 教育元素
- **灯泡**：高频易错点图标（暖金边框）
- **靶心**：一句话记忆图标（青碧边框）
- **螺旋笔记本**：左下角，学习计划区
- **打开的书本**：底部中央，象征学习
- **铅笔/钢笔**：右下角，书写元素

#### 禁用元素（默认风格）
- 倾斜/旋转的标签、便利贴、卡片
- 手绘涂鸦、气泡框、波浪线、感叹号、回形针、纸夹、和纸胶带
- 成片散布的装饰（仅角落小星可留）

## 内容模块详解

### 1. 封面页

**用途**：课程/打卡系列的封面

**必备元素**：
- 主标题（墨蓝粗体 + 柠檬黄直线下划线 + 暖金细双线，两侧对称暖金小星）
- 副标题（黛蓝，细柠檬黄下划线）
- 墨蓝标签（左上角，摆正）
- 柠檬黄便利贴（右上角，摆正）+ 编号小标签（下）
- 双线内框（暖金外线 + 黛蓝内线，四角暖金星簇，顶底暖金分隔线）
- 底部三枚主题图标卡片（雪白底暖金细边 + 小字标注）
- 装饰元素（角落星簇，页脚双图标）

**可选元素**：
- 学习计划（螺旋笔记本）
- 知识图谱（简图）
- 课程概览（小卡片）

### 2. 知识页

**用途**：知识点讲解

**必备元素**：
- 页眉（墨蓝标签 + 柠檬黄便利贴页码，均摆正）
- 标题（墨蓝）
- 分区卡片（墨蓝编号 + 白色内容 + 顶部色条）
- 高频易错点（灯泡图标，暖金边框，柠檬黄荧光笔高亮）
- 一句话记忆（靶心图标，青碧边框，柠檬黄高亮底）

**分区数量**：2-5个，根据内容量调整

### 3. 练习页

**用途**：配套练习题

**必备元素**：
- 题目列表（墨蓝编号圆圈）
- 答案区（可选）
- 提示区（可选，暖金文字）

## Prompt生成规则

### 维度填充顺序

1. **style**：确定整体风格（notebook_scrapbook，默认墨蓝手账）
2. **background**：纸张质感（cream_paper, torn_edge, hole_punches）
3. **layout**：页面布局（title_centered, sections_grid, 严格对齐）
4. **title**：主标题（墨蓝粗体 + 柠檬黄下划线）
5. **subtitle**：副标题（黛蓝）
6. **decorations**：装饰元素（标签、便利贴、角落小星——摆正不倾斜）
7. **sections**：内容分区（墨蓝编号 + 白色卡片 + 顶部色条）
8. **special_sections**：特殊模块（高频易错点暖金框、一句话记忆青碧框）
9. **icons**：图标（简约线条，黛蓝/雾蓝）
10. **aspect_ratio**：比例（3:4竖版或4:3横版）

### 文字处理

| 情况 | 处理 |
|------|------|
| 用户提供文字内容 | 直接使用 |
| 用户未提供 | 生成占位符，建议填写 |
| 语言 | 默认中文 |

### 比例选择

| 比例 | 用途 |
|------|------|
| 3:4 | 竖版知识卡片、打卡海报（默认） |
| 4:3 | 横版知识卡片 |
| 16:9 | 宽幅信息图 |
| 1:1 | 社交媒体分享 |

## 质量检查表

### 风格一致性
- [ ] 使用正确的配色系统（墨蓝、黛蓝、雾蓝、青碧、暖金、柠檬黄）
- [ ] 包含撕纸边缘和活页孔
- [ ] 使用白色圆角卡片（顶部色条）
- [ ] 标签/便利贴/卡片全部摆正不倾斜，装饰适度（角落小星/页脚图标/分隔线）
- [ ] 所有文字 BOLD 加粗渲染

### 内容完整性
- [ ] 标题清晰醒目
- [ ] 分区编号正确（一、二、三...）
- [ ] 高频易错点有灯泡图标
- [ ] 一句话记忆有靶心图标

### 视觉层次
- [ ] 标题 > 副标题 > 正文 > 重点
- [ ] 颜色使用符合规范
- [ ] 装饰不遮挡内容
- [ ] 留白适当，不拥挤
