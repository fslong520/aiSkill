# Step 3: GESP 知识点等级判定 + CF 难度定分

## 目标

两步独立评估：
- **知识点等级（GESP 1-8级 / CSP-J / CSP-S / NOI）**——用于 `tag` 的等级标签分类，**与定分无关**。
- **CF 难度评分（800~3500）**——写入 `problem.yaml` 的 `score`，与知识点等级**彻底解耦**。

## 原则

**知识点等级 ≠ 题目难度。** 同知识点可出简题亦可出难题。**先定级（分类），后定难（定分），二者互不映射。**

> ⚠️ 两条铁律：
> 1. **知识点等级只进 tag，不参与 CF 定分。** 定分一律走第四步「CF 评分档位判定」，不查等级、不查星级。
> 2. **CF 定分只认难度，不认知识点层级。** 同一"二维数组"知识，可出 800 的纯旋转输出，也可出 1400+ 的复杂应用。定分只按思维复杂度判据，绝不因"用到某数据结构/算法"自动加档。

## 第一步：前置分析（必做）

定级/定分前，先提取题面特征：

### 1.1 输入输出特征

| 特征 | 信息 | 提示 |
|------|------|------|
| 输入规模 | N 的最大值 | 判断算法复杂度要求 |
| 输出类型 | 单值/序列/构造 | 影响解法选择 |
| 多组数据 | T 的存在 | 可能涉及预处理 |

### 1.2 数据范围速判

| N 的范围 | 允许复杂度 | 常用算法 |
|----------|-----------|---------|
| N ≤ 20 | O(2^N) | 暴力枚举、位运算 |
| N ≤ 1000 | O(N^2) | 暴力DP、简单图论 |
| N ≤ 10^5 | O(N log N) | 二分、排序、线段树 |
| N ≤ 10^6 | O(N) | 贪心、前缀和、并查集 |
| N ≤ 10^9 | O(log N) 或 O(1) | 数学公式、矩阵快速幂 |

### 1.3 空间限制

| 限制 | 提示 |
|------|------|
| 256MB | 可开二维数组 |
| 64MB | 注意空间优化 |
| 16MB | 需滚动数组/压缩 |

## 第二步：定级（知识点分类，跨体系锚定）

**体系说明**：竞赛知识点跨越 GESP（1-8级，CCF等级认证）、CSP-J（入门）、CSP-S（提高）、NOI（国赛/省选段）四套体系。**先查 GESP 大纲；若知识点不在 GESP 表（超纲），则循 CSP-J → CSP-S → NOI 逐级找，取对应体系标注。** 等级标签写法见 2.6。

### 2.1 GESP 核心知识总览（CCF 2026 大纲）

| 级别 | 核心知识 | 定级提示 |
|:----:|---------|---------|

### 2.5 跨体系定级综合判定

#### 核心规则

1. **算法优先**：以最高级别算法为准定级（查 2.2 / 2.4）
2. **数据结构设下限**：题目所需数据结构决定最低等级（查 2.3 / 2.4），算法等级若高于此则取算法
3. **进阶结构保底**：命中 2.4 表者，按表定级，**禁低估**
4. **数学不计级**：组合数学、数论等理解性知识不计入定级（但**进阶数论算法**如逆元/快速幂除外，见 2.4）
5. **模板题降级（仅定级）**：若只需套模板，可酌情降一级——**但此降级仅降知识点等级，不影响 CF 定分**（定分独立判定）

#### 跨体系兜底规则（⭐ 新增）

> **GESP 查不到即升级找他**：题面知识点先查 GESP 大纲（2.1~2.3）；**若 GESP 1-8 级均无该知识点（超纲）**，则循下行升级查找（参考 2.4 表）：
> 1. 先在 **CSP-J**（入门难度1-5）找 → 归属 `CSP-J`
> 2. 再在 **CSP-S**（提高难度5-8，NOI大纲提高级）找 → 归属 `CSP-S`
> 3. 最后在 **NOI**（难度8-10）找 → 归属 `NOI`
> 4. **四级体系皆无** → 取最高可行级（宁可判高，不可低估），并记入 4.3 反例校准表反馈优化
>
> **判定顺序**：GESP → CSP-J → CSP-S → NOI，**取首个命中之体系**；若同时命中（如线段树 GESP八级 + CSP-S），取两者中较高归属标注。**禁因查不到而凭空降级。**

#### 等级边界判定

| 情况 | 判定 |
|------|------|
| 一级 vs 二级 | 有无嵌套循环 |
| 二级 vs 三级 | 有无数组/字符串操作 |
| 三级 vs 四级 | 有无递推/排序/二维数组/结构体 |
| 四级 vs 五级 | 有无二分/贪心/递归/链表 |
| 五级 vs 六级 | 有无DFS/BFS/DP/树/栈/队列 |
| 六级 vs 七级 | 有无复杂DP/图遍历/哈希表/并查集/堆 |
| 七级 vs 八级 | 有无最短路/MST/倍增/线段树/树状数组/算法优化 |
| **GESP 八级超纲** | 有无 AC自动机/Tarjan/网络流/可持久化/后缀自动机/计算几何/博弈论 → **CSP-S 高阶 或 NOI** |

## 第四步：定分（CF Rating 档位判定）

**目标**：为题目估算 Codeforces Rating（800~3500），写入 `score`，并作题面难度标注。

> ⚠️ **CF 分按难度，与 GESP/CSP/NOI 等级、星级、知识点完全脱钩。** 定分只认四维判据（思维拐点 / 算法门槛 / 数据规模 / 实现细节），AI 逐项判定后锁定档位，禁直接给一个感觉分。

### 4.0 已知 CF Rating（最高优先级）

若题目直接来自 Codeforces 且已知 Rating：
- **直接采用已知 Rating**，跳过判据判定
- 例：CF Round 某题 Rating 1400 → `score: 1400`

### 4.1 判据体系：四维打分（⭐ 核心，禁跳过）

定分前必先对下述四维逐项判定，**每一维必须给出明确结论**（禁含糊、禁跳步），再查 4.2 档位表锁定。

| 维度 | 判定要点 | 量化 | 结论示例 |
|------|---------|------|---------|
| **思维拐点** | 题目是否需"想一步"才见正解？零步=直做；一步=有拐点；多步=多拐点 | 零步 / 一步 / 多步 | 「二维数组旋转」→ 零步（直做输出） |
| **算法门槛** | 是否需特定算法（排序/二分/贪心/DP/图论/数据结构）？算法愈深门槛愈高 | 无 / 基础 / 进阶 / 高级 | 「线段树区间和」→ 高级（数据结构） |
| **数据规模** | N 是否要求效率思维？N≥10^5 需 O(N log N)，N≥10^6 需 O(N) | 小 / 中 / 大 | 「二维数组旋转 N≤1000」→ 小 |
| **实现细节** | 边界、字符串处理、构造输出、取模、精度是否繁琐？ | 简单 / 中等 / 繁琐 | 「纯旋转输出」→ 简单 |

> **档位规则**：
> 1. **逐项判定后，取全部命中档之最高档；任一维度未达更高档则不得升档。**
> 2. **水题就低不就高**：纯语法/直套模板/零思维 → **800**；禁因"用了某算法/数据结构"自动加档。
> 3. **宁低勿高**：拿不准取低档，勿虚高。
> 4. **取整至 50 的倍数**（800、850、900、950、1000…）。
