# Step 3: GESP 知识点等级判定 + CF 难度定分

## 目标

两步独立评估：
- **GESP 知识点等级（1-8级）**——用于 `tag` 的 `GESP X级` 分类，**与定分无关**。
- **CF 难度评分（800~3500）**——写入 `problem.yaml` 的 `score`，与 GESP 等级**彻底解耦**。

## 原则

**知识点等级 ≠ 题目难度。** 同知识点可出简题亦可出难题。**先定级（分类），后定难（定分），二者互不映射。**

> ⚠️ 两条铁律：
> 1. **GESP 等级只进 tag，不参与 CF 定分。** 定分一律走第四步「CF 评分档位判定」，不查 GESP、不查星级。
> 2. **CF 定分只认难度，不认知识点层级。** 同一"二维数组"知识，可出 800 的纯旋转输出，也可出 1400+ 的复杂应用。定分只按思维复杂度判据，绝不因"用到某数据结构/算法"自动加档。

## 第一步：前置分析（必做）

定级/定分前，先提取题面特征：

### 1.1 输入输出特征

| 特征 | 信息 | 提示 |
|------|------|------|
| 输入规模 | N 的最大值 | 判断算法复杂度要求 |
| 输出类型 | 单值/序列/构造 | 影响解法选择 |
| 多组数据 | T 的存在 | 可能涉及预处理 |

### 1.2 数据范围速判

| N 的范围 | 允许复杂度 | 常用算法 |
|----------|-----------|---------|
| N ≤ 20 | O(2^N) | 暴力枚举、位运算 |
| N ≤ 1000 | O(N^2) | 暴力DP、简单图论 |
| N ≤ 10^5 | O(N log N) | 二分、排序、线段树 |
| N ≤ 10^6 | O(N) | 贪心、前缀和、并查集 |
| N ≤ 10^9 | O(log N) 或 O(1) | 数学公式、矩阵快速幂 |

### 1.3 空间限制

| 限制 | 提示 |
|------|------|
| 256MB | 可开二维数组 |
| 64MB | 注意空间优化 |
| 16MB | 需滚动数组/压缩 |

## 第二步：GESP 定级（知识点分类）

**依据 CCF GESP 官方大纲（2026版）** 将题目所涉知识点归入对应级别。

### 2.1 核心知识总览（大纲节选）

| 级别 | 核心知识 | 定级提示 |
|:----:|---------|---------|
| 一级 | 变量、基本数据类型、顺序/分支/循环、基本运算、输入输出 | 无数组、无嵌套循环，仅有基础语法 |
| 二级 | 存储与网络、流程图、ASCII编码、数据类型转换、**多层分支/循环嵌套**、数学函数 | 有嵌套循环，但无数组/字符串操作 |
| 三级 | 数据编码、进制转换、位运算、算法描述、**一维数组、字符串、枚举法、模拟法** | 用到一维数组或字符串，或枚举/模拟算法 |
| 四级 | **指针、结构体、二维/多维数组、函数、递推算法、排序算法（冒泡/插入/选择）、文件操作、异常处理** | 用到二维数组/结构体/指针，或递推/排序算法 |
| 五级 | **初等数论、高精度运算、链表、二分查找/答案、递归、贪心、分治**（归并/快排） | 用到二分/贪心/递归/分治/数论/链表 |
| 六级 | **树、哈夫曼树、二叉排序树、DFS/BFS、简单动态规划（一维/背包）、面向对象、栈与队列** | 用到树/搜索/简单DP/栈/队列 |
| 七级 | **复杂动态规划（LIS/LCS/区间DP/二维DP/滚动数组）、图的定义与遍历、图论算法（flood fill）、哈希表** | 用到复杂DP/图遍历/图论基础/哈希表 |
| 八级 | 计数原理、排列组合、杨辉三角、**倍增法、图论算法综合（MST/最短路）、算法优化** | 用到最短路/MST/倍增/组合数学/算法优化 |

### 2.2 核心算法递进（大纲附录）

**判定时以题目所涉最高级算法为准。**

| 级别 | 核心算法 |
|:----:|---------|
| 一级 | 无特定算法，基础编程 |
| 二级 | 无特定算法，综合编程 |
| 三级 | 枚举法、模拟法 |
| 四级 | 递推算法、冒泡排序、插入排序、选择排序 |
| 五级 | 二分查找/二分答案、递归、贪心算法、分治（归并排序、快速排序） |
| 六级 | 深度优先搜索（DFS）、宽度优先搜索（BFS）、简单动态规划 |
| 七级 | 复杂动态规划（LIS、LCS、区间DP）、图遍历算法 |
| 八级 | 最小生成树、最短路径、算法优化 |

### 2.3 核心数据结构递进（大纲附录）

**若题目使用某级数据结构，其定级不可低于该级。**

| 级别 | 核心数据结构 | 说明 |
|:----:|-------------|------|
| 一级 | 基本数据类型（int、long long、float、double、char、bool） | 无复合结构 |
| 二级 | 无新增 | 仅有基本类型 |
| 三级 | **一维数组、字符串** | 用一维数组/字符串解题→下限三级 |
| 四级 | **二维/多维数组、结构体、指针** | 用二维数组/结构体/指针→下限四级 |
| 五级 | 链表（单链表、双链表、循环链表） | 用链表→下限五级 |
| 六级 | 栈、队列、循环队列、树、二叉树 | 用栈/队列/树→下限六级 |
| 七级 | 图（有向图、无向图）、哈希表 | 用图/哈希表→下限七级 |
| 八级 | 无新增（综合应用） | 综合运用已有知识 |

### 2.4 进阶结构与算法归类表（⭐ 补全超纲项）

> **症结所在**：GESP 大纲 2.1/2.2/2.3 仅列到"树/图/哈希/最短路"。但**实际题目常出现线段树、树状数组、堆、并查集、平衡树、单调栈等进阶结构，大纲无条目，AI 无据可依，凭感觉乱定为 5 级。** 下表补入，凡命中即定级锚定，禁低估。

| 结构/算法 | 定级 | 依据 |
|----------|:----:|------|
| **线段树**（含区间修改/查询、扫描线） | **八级** | 大纲八级「算法优化」，属最优级综合应用；**绝非六级以下** |
| **树状数组（BIT）** | **八级** | 同上，算法优化范畴 |
| **ST 表（RMQ）** | **八级** | 倍增思想，大纲八级「倍增法」 |
| **平衡树（Treap/Splay/FHQ）** | **八级** | 高级数据结构，算法优化 |
| **单调栈 / 单调队列** | **八级** | 算法优化（滑动窗口优化） |
| **优先队列（堆 / priority_queue）** | **七级** | 大纲六级的栈/队列进阶，常配哈夫曼树（六级）与图论（七级）；单独用堆解题→七级 |
| **并查集** | **七级** | 图论/集合连通基础算法，归七级图论 |
| **KMP / 字符串哈希 / AC 自动机** | **八级** | 算法优化与字符串高阶，大纲八级范畴 |
| **最短路（Dijkstra/Floyd/Bellman-Ford）** | **八级** | 大纲明确八级 |
| **最小生成树（Kruskal/Prim）** | **八级** | 大纲明确八级 |
| **拓扑排序 / 二分图判定** | **七级** | 图遍历/图论基础算法 |
| **逆元/快速幂/中国剩余定理** | **七级** | 初等数论进阶（五级数论延伸） |

> **超纲保护规则**：凡题目用到 2.4 表中【八级】之结构/算法，其 **GESP 定级不得低于八级**，除非题目仅为该结构之"模板输出演示"且无思维拐点（此时定级不变，勿混淆定级与定分——定级归级，定分另判，见第四步）。
> **超纲兜底**：题面出现大纲 2.1~2.3 之外（超纲）的任何算法/数据结构，一律**取最高可行级**，禁低估——宁可判高一级，不可偷懒降级。

### 2.5 定级综合判定

#### 核心规则

1. **算法优先**：以最高级别算法为准定级（查 2.2 节）
2. **数据结构设下限**：题目所需数据结构决定最低等级（查 2.3 节），算法等级若高于此则取算法
3. **进阶结构保底**：命中 2.4 表者，按表定级，**禁低估**
4. **数学不计级**：组合数学、数论等理解性知识不计入定级（但**进阶数论算法**如逆元/快速幂除外，见 2.4）
5. **模板题降级（仅定级）**：若只需套模板，可酌情降一级——**但此降级仅降 GESP 等级，不影响 CF 定分**（定分独立判定）

#### 等级边界判定

| 情况 | 判定 |
|------|------|
| 一级 vs 二级 | 有无嵌套循环 |
| 二级 vs 三级 | 有无数组/字符串操作 |
| 三级 vs 四级 | 有无递推/排序/二维数组/结构体 |
| 四级 vs 五级 | 有无二分/贪心/递归/链表 |
| 五级 vs 六级 | 有无DFS/BFS/DP/树/栈/队列 |
| 六级 vs 七级 | 有无复杂DP/图遍历/哈希表/并查集/堆 |
| 七级 vs 八级 | 有无最短路/MST/倍增/线段树/树状数组/算法优化 |

#### 定级示例

| 题特征 | 最高算法 | 数据结构 | 结构下限 | 是否 2.4 | 最终级 |
|-------|:-------:|:-------:|:-------:|:-------:|:-------:|
| 打印九九表，嵌套循环 | 无 | 基本类型 | 一级 | 否 | **一级** |
| 数组最大值 | 无 | 一维数组 | 三级 | 否 | **三级** |
| 二维数组旋转输出 | 无 | 二维数组 | 四级 | 否 | **四级**（数据结构下限） |
| 二分查找 | 二分（五级） | 一维数组 | 三级 | 否 | **五级** |
| 走迷宫 DFS | DFS（六级） | 二维数组 | 四级 | 否 | **六级** |
| 区间 DP（LIS/LCS） | 复杂DP（七级） | 一维数组 | 三级 | 否 | **七级** |
| Dijkstra 最短路 | 最短路（八级） | 图 | 七级 | 是 | **八级** |
| **线段树区间求和** | 线段树（八级） | 树 | 六级 | 是 | **八级**（2.4 保底，**禁 5 级**） |
| **并查集判连通** | 并查集（七级） | 图 | 七级 | 是 | **七级** |
| **堆维护最值** | 堆（七级） | 堆 | — | 是 | **七级** |

## 第四步：定分（CF Rating 档位判定）

**目标**：为题目估算 Codeforces Rating（800~3500），写入 `score`，并作题面难度标注。

> ⚠️ **CF 分按难度，与 GESP 等级、星级、知识点完全脱钩。** 定分只认四维判据（思维拐点 / 算法门槛 / 数据规模 / 实现细节），AI 逐项判定后锁定档位，禁直接给一个感觉分。

### 4.0 已知 CF Rating（最高优先级）

若题目直接来自 Codeforces 且已知 Rating：
- **直接采用已知 Rating**，跳过判据判定
- 例：CF Round 某题 Rating 1400 → `score: 1400`

### 4.1 判据体系：四维打分（⭐ 核心，禁跳过）

定分前必先对下述四维逐项判定，**每一维必须给出明确结论**（禁含糊、禁跳步），再查 4.2 档位表锁定。

| 维度 | 判定要点 | 量化 | 结论示例 |
|------|---------|------|---------|
| **思维拐点** | 题目是否需"想一步"才见正解？零步=直做；一步=有拐点；多步=多拐点 | 零步 / 一步 / 多步 | 「二维数组旋转」→ 零步（直做输出） |
| **算法门槛** | 是否需特定算法（排序/二分/贪心/DP/图论/数据结构）？算法愈深门槛愈高 | 无 / 基础 / 进阶 / 高级 | 「线段树区间和」→ 高级（数据结构） |
| **数据规模** | N 是否要求效率思维？N≥10^5 需 O(N log N)，N≥10^6 需 O(N) | 小 / 中 / 大 | 「二维数组旋转 N≤1000」→ 小 |
| **实现细节** | 边界、字符串处理、构造输出、取模、精度是否繁琐？ | 简单 / 中等 / 繁琐 | 「纯旋转输出」→ 简单 |

### 4.2 CF 档位判定表（⭐ 核心，锚点判据）

**判据 → 档位映射，全命中某档才得该档，宁低勿高。**

| CF 档区间 | 思维拐点 | 算法门槛 | 数据规模 | 实现 | CF 锚点（代表题） |
|:---------:|:-------:|:-------:|:-------:|:----:|------------------|
| **800** | 零步 | 无 | 小 | 简单 | 4A Watermelon / 71A Way Too Long Words / 50A Domino piling / 231A Team |
| **900** | 零~半步 | 无 | 小 | 简单 | 96A Football / 118A String Task / 58A Chat Room |
| **1000** | 一步 | 无~基础 | 小中 | 简单 | 263A Beautiful Matrix / 617A Elephant |
| **1100** | 一步 | 基础（枚举/模拟） | 中 | 简单 | 160A Twins / 41A Translation |
| **1200** | 一步 | 基础（二分/简单贪心） | 中 | 中等 | 266A Stones / 208A Dubstep |
| **1300** | 一步+ | 基础算法组合 | 中 | 中等 | 25A IQ test / 189A Cut Ribbon |
| **1400** | 多步 | 常规算法（DP/排序/图基础/数论） | 中大 | 中等 | 455A Boredom / 363B (常为 1400) |
| **1500** | 多步 | 常规算法 + 边界思维 | 中大 | 中等 | 478C / 493C |
| **1600** | 多步 | 进阶算法（DFS/BFS/简单DP/最短路） | 大 | 中等 | 339C / 580C（BFS） |
| **1800** | 多步+ | 数据结构（线段树/并查集/单调栈/堆） | 大 | 繁琐 | 474D / 1076E（线段树） |
| **2000** | 多步+ | 高级算法组合（图论综合/复杂DP） | 极大 | 繁琐 | 555E / 845G |
| **2200+** | 多拐点 | 高难竞赛（网络流/高级数据结构/数学综合） | 极大 | 极繁 | 985E / 1061D（近 2200） |

> **档位规则**：
> 1. **逐项判定后，取全部命中档之最高档；任一维度未达更高档则不得升档。**
> 2. **水题就低不就高**：纯语法/直套模板/零思维 → **800**；禁因"用了某算法/数据结构"自动加档。
> 3. **宁低勿高**：拿不准取低档，勿虚高。
> 4. **取整至 50 的倍数**（800、850、900、950、1000…）。

### 4.3 反例校准表（⭐ 针对已现乱评）

| 真题特征 | 错误评分 | 正确评分 | 判据分析 |
|---------|:-------:|:-------:|---------|
| **简单二维数组旋转**（无思维拐点，纯 O(N²) 遍历赋值） | ~~1400~~ | **800~900** | 思维零步 + 算法门槛无 + 数据小 + 实现简单 → 800 档。**1400 严重虚高**，违背水题就低 |
| **线段树区间和**（高级数据结构） | GESP ~~5级~~ | **GESP 8级** | 2.4 表保底八级，禁低估（注意：定级归八级，CF 分另判） |
| **纯数组求最大最小** | GESP 二级 | **GESP 三级** | 一维数组下限三级 |

> **判据自问（定分前必答）**：
> - 此题在 CF 上**最接近哪道题**？其 Rating 是多少？
> - 我给的分数，**落到 4.2 哪一档**？该档四维判据是否全命中？
> - 若是简单题，**是否克制在 ≤900**？

### 4.4 定分记录（必填）
