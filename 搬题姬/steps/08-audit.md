# Step 8: 审计

## 目标

审计已生成之全部题包内容，确：
1. 文件结构完整、与模板一致
2. GESP 等级判定正确（对照 03-gesp.md）
3. 难度分值 score 判定正确（对照 03-gesp.md 第六步：AI 独立分析）
4. CF 分数为 AI 独立分析，无速查表/公式套用之误（对照 03-gesp.md 第六步）
5. source 出处字段正确（搬运题必填原始题页 URL，原创题可空）

**全过方可打包。有误则修正后重审。**

## 8.2 题面模板一致性

- [ ] `problem_zh.md` 以 `<div class="water">` 起
- [ ] 标题格式 `中文(英文)`，例：`移除前导o(Trimo)`

- [ ] `</div>` 前含 **测试点分布** 表格（含 Subtask/分值/测试点编号/说明四列及所有 subtask 分组）
- [ ] 含 **知识点与难度** 行，格式 `本题涉及的知识点从属于 **GESP X级**，难度（CF Rating）：**XXXX**`（CF 分数与 problem.yaml 的 score 一致）
- [ ] URL 来源者：**题面末尾（`</div>` 前）** 含出处行 `> 出处：[原题链接](URL)`，URL 与 problem.yaml 的 source 一致
- [ ] 样例输入/输出与原始题面一致，未增删改
- [ ] 图片链接处理正确：互联网链原样保留，本地图置于 `additional_file/` 且引用为 `file://` 前缀
- [ ] 示意图、表格、公式完整保留

## 8.3 配置模板一致性

- [ ] `problem.yaml` 含 `pid` 字段（合法格式 or null）
- [ ] `title` 字段格式 `中文(英文)`
- [ ] 搬运题 `source` 字段为非空 URL（以 `http://` 或 `https://` 起）；原创题可空或省略
- [ ] `score` 字段非空，且位于 800~3500 区间
- [ ] URL 来源者：`source` 字段非空且为合法 URL（与题面出处行一致）
- [ ] `tag` 含 1~3 个知识点标签 + 1 个 `GESP X级` 标签（禁仅一个等级标签）
- [ ] `GESP X级` 中 X 与 "级" 间有空格
- [ ] `testdata/config.yaml` 总分 = 100
- [ ] `testdata/config.yaml` 含顶层 `time` 与 `memory`

## 8.4 GESP 等级复核

按 **03-gesp.md** 第三步（定级）重验定级之逻辑：

- [ ] 算法识别完整——题中所有算法皆已识别，未遗漏
- [ ] 取最高级别——按最高级算法定级，非次级
- [ ] 数据结构不独立定级——未错以数据结构（如数组、哈希表）为定级依据
- [ ] 数学不计级——组合数学、数论等理解性知识未误入定级
- [ ] 对照常见误判速查表（03-gesp.md 4.2 节）——无同类错误

**若以上任一条不通过，则回 03-gesp.md 重走定级流程。**

## 8.5 分值复核

按 **03-gesp.md 第六步（定分：AI 独立分析）** 重验 score：

- [ ] `score` 取整至 50 倍数（800、850、900、950、1000…）
- [ ] CF 已知 Rating 者直接采用（非估算）
- [ ] 定分为 **AI 独立分析**，未查速查表、未套公式、未按 GESP 等级/星级映射（GESP 等级只进 tag）
- [ ] 水题给分克制——零思维量者 ≤900，纯语法直套模板者 800
- [ ] 最终 score 落于合理区间（不偏离类似 CF 题 ±200）

**分值分析记录**：

```
类比 CF 题: {最接近的 CF 题 → Rating}
通过率视角: {Div 几几档 → 区间}
思维量: {零步/一步/多步}
取定: score = {最终值}
```

## 8.6 AtCoder 题 CF 分复核

仅若题目来自 AtCoder：

- [ ] 题面 Difficulty 值（若有）已正确取到，用作量级参考（非凭印象猜测）
- [ ] **最终分由 AI 独立分析定**，未按换算表机械套分
- [ ] 水题给分克制（零思维量者 ≤900）
- [ ] score 取整至 50 倍数

复核记录：

```
题目来源: AtCoder {contest_name} {problem_letter}
Difficulty 值: {有/无} → {值}
AI 分析过程: {类比/通过率判断}
取定: score = {最终值}
```
