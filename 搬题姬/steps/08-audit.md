# Step 8: 审计

## 目标

审计已生成之全部题包内容，确：
1. 文件结构完整、与模板一致
2. 知识点等级判定正确（对照 03-gesp.md 第二步 + 2.4 跨体系锚定表）
3. 难度分值 score 判定正确（对照 03-gesp.md 第四步：CF 档位判定）
4. CF 分数为逐项判四维锁定档位，无速查表/公式套用/GESP等级映射之误（对照 03-gesp.md 第四步）
5. source 出处字段正确（搬运题必填原始题页 URL，原创题可空）

**全过方可打包。有误则修正后重审。**

## 8.4 GESP 等级复核

按 **03-gesp.md 第二步（定级：知识点分类）+ 2.4 跨体系锚定表** 重验定级之逻辑：

- [ ] 算法识别完整——题中所有算法皆已识别，未遗漏
- [ ] 取最高级别——按最高级算法定级，非次级
- [ ] 数据结构不独立定级——未错以数据结构（如数组、哈希表）为定级依据
- [ ] **进阶结构查 2.4 表——线段树/树状数组/并查集/堆/平衡树/最短路/AC自动机/网络流/计算几何等是否按表锚定，禁低估（线段树≠5级）**
- [ ] **跨体系兜底（2.5）——GESP 大纲无此知识点者，是否升到 CSP-J/CSP-S/NOI？禁定格在 GESP 级**
- [ ] 数学不计级——组合数学、数论等理解性知识未误入定级（进阶数论算法如逆元/快速幂→七级除外）
- [ ] 对照常见误判速查表（03-gesp.md 第三步：自查清单）——无同类错误

**若以上任一条不通过，则回 03-gesp.md 重走定级流程。**

## 8.5 分值复核

按 **03-gesp.md 第四步（CF 档位判定：四维判据）** 重验 score：

- [ ] `score` 取整至 50 倍数（800、850、900、950、1000…）
- [ ] CF 已知 Rating 者直接采用（非估算）
- [ ] 定分为**逐项判四维锁定档位**，未查速查表、未套公式、未按 GESP 等级/星级映射
- [ ] 水题给分克制——零思维量者 ≤900，纯语法直套模板者 800
- [ ] 最终 score 落于合理区间（不偏离类似 CF 题 ±200）

**分值判定记录**（对照 03-gesp.md 4.4 节填写）：

```
四维判定:
  思维拐点: {零步/一步/多步}
  算法门槛: {无/基础/进阶/高级} + {具体算法或数据结构}
  数据规模: {小/中/大} + {N最大值}
  实现细节: {简单/中等/繁琐}
匹配档位: {03-gesp.md 4.2 表某项，CF区间}
类比 CF 题: {最接近的 CF 题 → Rating}
取定: score = {最终值，50倍数}
```
