# LH6 周年庆促销利益点（统一口径）

> 所有活动页、活动说明、推送和素材中的周年利益点，以本文件为唯一来源。具体权益和适用条件以官方活动页为准。

## 标准利益点文案

```text
续费低至 1 折，拼团成功再送 1 或 3 个月时长。
新购低至 4.5 折，拼团成功再送 3 个月时长。
境内 2核4G5M、2核4G6M 可免费升配至 4核4G。
具体权益以官方活动页为准，最终解释权归主办方所有。
```

## 使用边界

- “1 或 3 个月时长”必须以活动页的实际规则为准，不得擅自承诺具体档位。
- 仅限已确认的境内 2核4G5M、2核4G6M 免费升配至 4核4G；不得扩展到其他配置。
- 不使用“最低”“最划算”“必得”“翻倍”等绝对化或保证性表述。
- 抽奖仍使用“随机抽取、以实际抽奖结果为准”，不承诺必中。
