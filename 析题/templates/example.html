AtCoder ABC457 启发式

A最大值

题面

题目描述

给定 $n$ 个整数 $a_1, a_2, \dots, a_n$，输出其中最大值。

输入格式

第一行一个整数 $n$。第二行 $n$ 个整数 $a_i$。

输出格式

一行一个整数，表示最大值。

数据范围

$1 \le n \le 10^5$，$|a_i| \le 10^9$

样例

标准输入： 5 3 9 1 7 2 标准输出： 9

题目一句话

遍历所有数，记住当前最大。

怎么想

第一反应：暴力两两比，非要分出个高低。可一瞧数据范围 $n \le 10^5$——两两比较那是 $O(n^2)$，$10^{10}$ 次操作，够你数到地老天荒。

冷静。找最大值，谁说要排序了？扫一遍：手里攥一个"当前最大"，来一个数就比一下，遇大的就换人。一趟走完，答案在手。任何"找最值"题都是这个套路——别把简单事办复杂了。

关键点

一句点透：最大值不需要排序，扫一遍记一个变量就够了。

逻辑链

flowchart TD
Start([开始]) --> Init["mx = -inf"]
Init --> Loop{"还有数吗?"}
Loop -->|是| Read["读下一个数 x"]
Read --> Cmp{"x > mx?"}
Cmp -->|是| Upd["mx = x"]
Upd --> Loop
Cmp -->|否| Loop
Loop -->|否| Out["输出 mx"]
Out --> End([结束])

style End fill:#7f9a83,color:#fff

样例演示

输入 3 9 1 7 2，跟踪 mx 的变化：

步骤当前数mx 更新mx 值
133 > -inf ✓3
299 > 3 ✓9
311 > 9 ✗9
477 > 9 ✗9
522 > 9 ✗9

最终输出 9 ✓

复杂度

时间
O(n)
空间
O(1)

参考代码

#include <iostream>
#include <climits>
using namespace std;

int main()
{
    int n; cin >> n;
    int mx = INT_MIN;   // 初始化为最小可能值
    for (int i = 0; i < n; i++)
    {
        int x; cin >> x;
        if (x > mx) mx = x; // 遇更大则更新
    }
    cout << mx << endl;
    return 0;
}
点评：INT_MIN 是 <climits> 提供的，比随意初始化为 0 更安全（输入可能全负）。

易错点

曾踩坑：mx 初始化为 0？小心输入全负——-5, -3, -8 一路比下来，最后输出 0，可 0 压根没在输入里出现过！当年半个班栽这儿。老老实实初始化为 INT_MIN，或者拿第一个输入当起点。

B有序数组的两数之和

题面

题目描述

给定一个升序排列的整数数组 $a$ 和一个目标值 $t$，找出数组中两数之和等于 $t$ 的下标（假设恰好存在唯一解，下标从 1 开始）。

输入格式

第一行两个整数 $n$ 和 $t$。第二行 $n$ 个升序整数 $a_i$。

输出格式

一行两个整数，两数的下标（1-based）。

数据范围

$2 \le n \le 10^5$，$-10^9 \le a_i, t \le 10^9$

样例

标准输入： 5 11 2 7 9 11 15 标准输出： 1 3

题目一句话

升序数组里找两个数，和为 $t$。

怎么想（含歧路）

第一反应：暴力枚举，两层循环挨个试——$O(n^2)$，$n=10^5$ 时 $10^{10}$ 次操作，这速度够你从北京一路排到巴黎。

卡住：能不能少算点？等等……题目开头写着"升序"两个字，一直没派上用场。

转折观察：题目都给你排好队了，还傻傻地两两配对所有组合？看两端——如果 $a_l + a_r < t$，说明左边的兄弟太矮，左指针往右挪；如果 $a_l + a_r > t$，说明右边的兄弟太高，右指针往左撤。这就是双指针：两个侦探从两端包抄，谁不合要求谁先动，$O(n)$ 一趟拿下。

多解法递进

解法一：暴力枚举 $O(n^2)$

for (int i = 0; i < n; i++)
    for (int j = i + 1; j < n; j++)
        if (a[i] + a[j] == t) { cout << i+1 << ' ' << j+1; return 0; }

简单但太慢——$n=10^5$ 时跑不动。

解法二（最优）：双指针 $O(n)$

#include <iostream>
using namespace std;

int a[100005];   // 全局数组（OI 风格：少用 vector）

int main()
{
    int n, t; cin >> n >> t;
    for (int i = 0; i < n; i++) cin >> a[i];

    int l = 0, r = n - 1;   // 左指针、右指针
    while (l < r)
    {
        int s = a[l] + a[r];
        if (s == t) { cout << l+1 << ' ' << r+1; return 0; }
        else if (s < t) l++; // 和太小，左指针右移
        else r--;            // 和太大，右指针左移
    }
    return 0;
}
点评：双指针精髓在于"升序"让每次移动都有确定方向——和小于 t 时左指针右移一定增大和，而非盲目试探。

关键点

一句点透：升序 + 双指针 = 每次移动都是确定性的，$O(n)$ 扫一遍。

逻辑链

flowchart TD
Start([开始]) --> Init["l = 0, r = n-1"]
Init --> Loop{"l < r?"}
Loop -->|是| Sum["s = a[l] + a[r]"]
Sum --> Eq{"s == t?"}
Eq -->|是| Found["输出 l+1, r+1"]
Eq -->|否| Lt{"s < t?"}
Lt -->|是| LUp["l++"]
LUp --> Loop
Lt -->|否| RDown["r--"]
RDown --> Loop
Loop -->|否| NotFound["无解"]

易错点

曾踩坑：题目说"下标从 1 开始"，一激动输出成 0-based，白丢一题。双指针终止条件是 l < r 而非 l <= r——两数不能是同一个元素，不然左手打右手算怎么回事。
曾踩坑：把"升序"这个前提丢了——乱序数组不能直接双指针，得先排序（$O(n \log n)$），那又是另一道经典题了。审题不细，悔之晚矣。
串讲：A 题是线性扫描的入门——扫一遍记最值；B 题是双指针的经典——利用排序性质把 $O(n^2)$ 降为 $O(n)$。两题骨子里都是"利用数据性质减少多余比较"，区别在于 A 题只用一个变量，B 题用两个指针。后续 C、D、E 题（略）在此基础上增加了状态压缩和 DP 递推，但核心思维一脉相承。
