# 各科板书模板（学神笔记风）

所有模板共用结构：外框 + 标题栏 + 内容分区 + 分隔线 + 练习区。

## 进制转换

```
┌──────────────────────────────────────────────┐
│  进制转换笔记                                 │
│  十进制 ↔ 二进制                              │
│  ───────────────────────────────────────     │
│                                               │
│  十进制 → 二进制             二进制 → 十进制  │
│  除2取余法                   按权相加法       │
│  13÷2=6…余1 ↑              1101₂ = 1×2³+…  │
│  6÷2=3…余0 ↑               = 8+4+0+1 = 13  │
│  3÷2=1…余1 ↑                                 │
│  1÷2=0…余1 ↑  倒序：1101                     │
│                                               │
│  ── 练一练 ──                                │
│  25→？  1010→？                              │
└──────────────────────────────────────────────┘
```

## 二次函数

```
┌──────────────────────────────────────────────┐
│  二次函数笔记                                 │
│  y = ax² + bx + c                            │
│  ───────────────────────────────────────     │
│                                               │
│  标准形式          图像                       │
│  y=ax²+bx+c       y=x² 抛物线                │
│  a≠0              开口向上                    │
│  顶点 x=-b/2a     顶点 (0,0)                 │
│                对称轴 x=0                     │
│                                               │
│  ── 练一练 ──                                │
│  y=x²+2x+1  开口？顶点？对称轴？            │
└──────────────────────────────────────────────┘
```

## 英语语法

```
┌──────────────────────────────────────────────┐
│  英语时态笔记                                 │
│  Verb Tenses                                 │
│  ───────────────────────────────────────     │
│                                               │
│  一般现在时                  一般过去时       │
│  I eat / He eats            I ate            │
│  表示习惯/事实              表示过去动作      │
│                                               │
│  现在进行时                  将来时           │
│  I am eating                I will eat       │
│  表示正在发生               表示将要发生      │
│                                               │
│  ── 小练习 ──                                │
│  She ___ (go) to school yesterday.          │
└──────────────────────────────────────────────┘
```
