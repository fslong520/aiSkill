# 02 标题公式与结构模板

## 三、标题——300毫秒定生死

公众号平均打开率仅1.13%。标题决定100个粉丝里那一个人是否点开。

### 五大吸睛公式

| 公式 | 结构 | 示例 |
|------|------|------|
| **数字+具体承诺** | 数字 + 可量化收益 | 《3个方法，让工作效率提升200%》 |
| **身份标签+痛点** | 特定人群 + 扎心问题 | 《95后职场新人必看！这3个坑90%的人都踩过》 |
| **冲突对比+反差** | 否定旧认知 + 引出新观点 | 《别再追风口了，真正的高手都在做这件事》 |
| **情绪词+悬念** | 情绪词 + 留白/省略 | 《婆婆竟然这样说…让100万妈妈泪崩》 |
| **强调词+损失厌恶** | 千万/一定/别 + 错过损失 | 《千万别用这3个方法减肥！越减越胖》 |

### 标题自检清单

- □ 字数适中（手机端不截断）
- □ 核心词在前半段
- □ 包含情绪词或制造好奇心
- □ 目标读者一眼认出"这是写给我的"
- □ 包含搜一搜高频关键词
- □ 准备几个备选标题，选最佳

### 底层心理学

- **信息缺口**——标题制造"不完整感"，大脑自动想补全
- **损失厌恶**——"别再犯这5个错误" 比 "学会这5个技巧" 打开率高约15%
- **社交认同**——"为什么越来越多的年轻人选择这样做" 暗示社会趋势，怕落伍者必点

**关键原则：标题与内容必须匹配。** 标题党短期拉高点击率，但读者读完发现落差大就不会分享，算法将"高点击低分享"判定为低质内容并降权。

## 四、结构——让读者一口气读完

结构控制阅读节奏。**开头前150字决定读者是否划走。**

### 五种经验证爆文结构

#### 模板一：故事型（情感/个人成长）
```
悬念开头 → 事件起因 → 情节转折 → 升华结尾
```
适合个人经历分享、案例分析。用真实故事降低防御心，自然引出观点。

#### 模板二：并列型（方法论/技巧分享）
```
问题提出 → N个方法平行展开（每个独立完整）→ 总结提炼
```
最常见，写作有条理，读者看得清。注意每个案例之间要有区分度。

#### 模板三：逻辑型（知识科普/深度分析）
```
是什么 → 为什么 → 怎么做
```
SCQA模型变体：情境（Situation）→ 冲突（Complication）→ 问题（Question）→ 答案（Answer）

#### 模板四：清单型（工具推荐/资源整理）
```
全貌表格（快速扫描）→ 逐项深度展开 → 行动清单收尾
```
信息密度高，收藏率高。每个工具篇幅大致相当，不厚此薄彼。

#### 模板五：观点争议型（立靶子/辩立场）
```
立靶（摆出一个主流做法或流行观点）→ 拆解（指出它的毛病）→ 立论（给出自己的观点）→ 证明（案例/数据佐证）
```
适合"我为什么说 XX 是错的"类文章。传播力强——读者转发是在表态。注意：靶子要真、拆解要讲理，不能为杠而杠。

### 三明治干货法（内容填充）

```
上层：引发共鸣的案例/故事
中层：结构化的知识体系（理论框架）
底层：数据/事实背书
```

例：《斯坦福学霸的5大深度工作法》，先讲MRI数据证明专注者大脑灰质密度高23%（底层），再讲5个方法（中层），每个方法配实战故事（上层）。

### 开头怎么写——前150字定生死

开头只有一个任务：**让读者停下来，愿意继续往下读。**

不要铺垫、不要寒暄、不要"今天想和大家聊聊"。第一句就进入内容。

开头的方向有很多，可以是一个场景（"周五下午五点半，正准备关电脑，领导发来了微信"）、一个反问（"你有没有过这种感觉？题刷了不少但 rating 就是不涨"）、一个反差（"很多人觉得学算法要从原理开始。我以前也这么想，直到我用了另一种方式"）、一个反常识的数据、或者一个短故事。无论哪种，核心都是让读者产生"这说的就是我"的共鸣。

**开头自检三问：**
- 第一句有没有进入内容？（还是在铺垫寒暄？）
- 读者能不能在 3 秒内知道"这篇跟我有关"？
- 有没有制造好奇心缺口？（读者想不想知道答案？）

### 结尾怎么写——决定转发率的最后一步

结尾不是总结，是**最后一次情绪冲击 + 行动指令**。

不要"综上所述"、不要"希望对你有所帮助"、不要"让我们一起努力"。这些是 AI 的标准收尾，人不会这么说话。

结尾的方向：可以是一句金句（"放弃理解，就是放弃积累本身"），可以回扣开头形成闭环，可以给一个行动指令（"今天就去试一道题"），可以留白让人回味，如果是系列文还可以预告下一篇。无论哪种，最后一句一定要短——长句收尾没力量，短句才有冲击力。

**结尾自检三问：**
- 有没有说空话？（"希望对你有帮助"这类全是空话）
- 读者读完有没有想转发的冲动？（或想收藏？或想评论？）
- 最后一句够不够短？

### 段落节奏控制

- **开门见山**：直接告诉读者"这篇解决你什么问题"。无寒暄无铺垫。
- **段落不宜太长**：手机上密密麻麻像一堵墙，读者直接划走。
- **每过一段设一个"钩子"**：用提问/反转/悬念拉住注意力，防止中途离开。
- **结尾给出行动号召**：不引导，用户就不会动。"若对你有用，点个赞，转给一个正迷茫的朋友。"
