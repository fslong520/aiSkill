# 02 结构组织

结构不为套模板，为让材料自然流动。**先有材料和判断，再谈怎么组织。** 以下三种是材料最自然的三种走法，不是必选模板。

## 三种组织方式

### 讲故事——事情本身有过程

按经过写：起因 → 转折 → 结果 → 你后来明白了什么。

适合有完整经历的题材。读者跟着经过走，不费力。

### 列要点——几个点并列

每点独立说透：一个问题 → 几个做法/观点 → 各自展开 → 收个总。

适合方法论、干货。每个点之间要有实质区别，不能换个说法凑数。

### 层层深入——一个道理往深里挖

是什么 → 为什么 → 意味着什么 → 你怎么办。

适合观点、分析。每层比上层深一步，读者跟着你走完一趟。

**写之前自问：我的材料最像哪种走法？** 不像，就换。别为了结构把材料硬掰进去。

## 标题

标题只有一条铁律：**诚实。** 标题与内容不匹配，读者读完不分享，算法把"高点击低分享"判为低质，降权。

其余是建议：

- 核心词靠前半段。
- 具体胜过夸张。"让工作效率提升200%"不如"我这样改，一周少加了8小时班"。
- 标题是承诺，内容要兑现。

## 开头

第一句就进入内容。不要铺垫、不要寒暄、不要"今天想和大家聊聊"。

开头只有一个任务：让读者在3秒内知道"这篇跟我有关"。可以是一个场景、一个反问、一个反常识的数据、一件刚发生的事。

## 结尾

结尾是情绪落点，不是总结。

不要"综上所述""希望对你有帮助""让我们一起努力"——这些是AI的标准收尾，人不会这么说话。

最后一句要短。长句收尾没力量，短句才有冲击力。可以是一句你自己的判断，可以回扣开头，可以一个具体的行动建议。
