# 06 硬禁令与改稿

## AI 改写方向——从初稿到人稿

AI 初稿是骨架，改写才是血肉。方向四条，具体怎么改由你自己判断——原则是"每个观点要落地，每句话要像人说的"。

1. **加锚点**——每个抽象结论后面跟一个具体的人、事、数据或场景。全是观点没有锚点，AI 味最重。
2. **换语气**——把书面词换成说话词。"值得一提的是"→删掉；"综上所述"→删掉；"事实上"→"其实"。
3. **拆长句**——找每段最长的句子，拆成两句。长句之间插一个短句，制造节奏断裂点。
4. **磨结尾**——最后一句改成短句。长句收尾没力量。

改完读一遍。读着像人说话，就成了。读着像念稿，继续改。

## 硬禁令——成稿绝对不能出现

以下各项覆盖标题、小标题、正文、图片说明与引用转述。命中一项就不能交稿。**修改违禁句时，先找它原本想说的事实，再用普通句子说出来。不要寻找另一种漂亮句式替换。**

| 类别 | 禁止内容 |
|------|---------|
| **冒号** | 中文冒号 `：`、英文冒号 `:`（网址、代码与机器字段除外） |
| **破折号** | `—`、`——`、`–` |
| **翻案句** | "不是……而是……""并非……而是……""不在于……而在于……""与其说……不如说……""不只……还/也……""表面……实际……""看似……实则……"及其变形 |
| **硬停词** | "不丢""说白了""说穿了""先说结论" |
| **洞察路标** | "更微妙的是""还有一层""只说对了一半""值得注意的是""需要指出的是""从某种意义上说"给段落或句子抬价时禁用（本义指楼层、数量时不受影响） |
| **商业黑话** | 赋能、抓手、闭环、能力沉淀、打法、拉通、底层逻辑、顶层设计、认知跃迁、价值释放、降本增效、内容矩阵、全链路、组合拳、想象空间、结构性机会、深层逻辑、方法论、颗粒度、对齐（本义是化学沉淀、排版对齐等时保留）……改成人、动作、钱、时间与后果 |
| **借喻包装** | 非虚构内容不用仓库、抽屉、温度、死亡、坍塌、浪潮、钥匙、底座等借喻包装抽象概念。文章真的在写这些东西时不受影响 |

**原话命中这些禁令时，改成转述或省略，不能靠引号保留。**

## 改稿流程——先救人，再清句子

改稿的目标不是把文章修到无懈可击。**先保护已经活着的地方，再拆掉模型摆出来的姿势。**

1. **看谁在说**——哪几段换一个模型也能原样写出来，优先处理。现实稿补信息来路与具体材料，没东西可补就删。不要用增加"我觉得""说真的"修复匿名感，声音来自取舍，不来自代词。
2. **看有没有往前走**——给每段标一个主要作用（动作/事实/解释/例子/疑问/判断/背景）。连续几段做同一件事，通常会拖。做一次压缩试验：删掉三分之一后事实、动作、判断和阅读体验几乎没变，原稿就是在注水。
3. **拆表演性中文**——假深刻（单独截图好看、放回正文没用的句子）、假具体（没有来源的精确时间/天气/神态/房间摆设/突然出现的原话）、假口语（"老铁""兄弟们"这类硬凹称呼）、抽象名词堆叠（一句话能换进十篇商业文章，说明它没有当前材料）、比喻换场（800字内出现三套以上借喻）。
4. **听中文顺不顺**——读出声。主干早点来：先找做事的人，把他与动作放到前面，原因、时间、条件接到后面。前一句把什么交给了后一句：后句接住前句刚出现的人、物、动作或结果。停顿有轻重：短句放长句后面能压住一句，每段都这样收尾就是模型鼓点。单音节词更近口语（"买"不写"购买"），别整篇都换成正式长词。
5. **清禁用项**——按上面的硬禁令逐条搜索。禁用项没有清零，不能交稿。
6. **核现实**——现实稿核时间、数字、身份、引语、因果与第一人称动作。核验说明留在后台，不写进正文。
7. **查结尾**——把最后两段分别删掉再读，删掉更有力就让文章提前结束。最后一段重新概括全文，即使概括得很漂亮也先删掉。正文没持续处理"时代、文明、未来、世界、历史、所有人"尺度，结尾就回到具体事实、人物动作或当前判断。
