# 示例：《将进酒》改编 —— 全流程演示

> 本文档演示风咏完整流程：解析考据 → 叙事骨架 → 作词 → 定曲 → 输出。
> 供 AI 参考输出形态与质量标杆。
>
> ⚠️ **v1.0 早期示例**：本示例歌词含较多原句直引，
> 已依 2026-08-13 新规校准——**名句直引至多 2 处，同句不重复**。
> 本示例保留以展示流程形态，直引数量不作当前标准。

## 阶段 1-2：解析报告

```
📖 解析报告
【原作】《将进酒》 李白 盛唐（约 752 年，赐金放还后）
【主题】怀才不遇，纵酒狂歌，以醉忘忧
【情感基调】豪放悲壮 + 旷达（主豪放，副旷达）
【核心意象】黄河、白发、酒、钟鼓馔玉、五花马、千金裘
【名句】君不见黄河之水天上来（首）、天生我材必有用（中）、
       千金散尽还复来（中）、与尔同销万古愁（末）
【前因】李白被玄宗"赐金放还"，政治理想破灭；与岑勋、元丹丘会饮嵩山，
       借酒发狂言，实为失意之鸣（来源：《李白集校注》题解）
【后果】千古传诵，凡失意人、狂放者皆引为知己；"天生我材"成激励语
```

## 阶段 3：叙事骨架

```
🎵 叙事骨架
【前因】主歌1：长安金殿放还，会饮嵩山（点破不遇）
【本体】主歌2：黄河奔流、白发朝暮、人生苦短（意象展开）
【副歌】君不见黄河之水天上来 / 天生我材千金散尽还复来（直引+裁句合璧）
【桥段】千年醉客同举杯——今人对望（后果）
【尾声】五花马千金裘换酒，与尔同销万古愁（留白收束）
【情感曲线】平静(起) → 苍凉(承) → 爆发(转) → 旷达余韵(合)
```

## 阶段 4-6：完整输出

```
🎼 《与尔同销万古愁》—— 改编自《将进酒》
【一句话】一个失意的人，把万古的愁倒进了酒里

【歌词】

[主歌1]

功名散作云烟，我策马出金阶
嵩山月下故人设宴
三杯下肚，再说这一生不遇的哀

[预副歌]
君不见——
那河水滔滔，可曾回头望一眼？

[主歌2]

奔流到海，不复回
天生我材，千金散尽还复来
与君同饮三百杯，三百杯

[主歌3]
钟鼓馔玉，过眼如浮云
我只要一醉，便忘了这世间

[副歌]

奔流到海，不复回
天生我材，千金散尽还复来

[桥段]
千百年后也有人举杯
敬你醒眼看世态，醉里写真言
失意的人共一醉
万古的愁，都化作了烟

[尾声]
五花马，千金裘
呼儿将出换美酒
与尔同销，万古愁

【曲风方案】
🎵 曲风：国风摇滚
BPM：120
调式：五声宫调，桥段转升半音，尾声回落
配器：钢琴分解和弦起 → 民乐鼓+电吉他入副歌 → 笛声点缀副歌尾；桥段减配器 → 末段副歌全开

情绪线：平静起 → 苍凉 → 爆发 → 转调升华 → 余韵收
