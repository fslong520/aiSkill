# 风咏 - 古诗文改编写歌

## Summary
读透原文与背景 → 立前因本体后果叙事骨架 → 原文化用成词 → 配曲风编曲方案。歌词浑然一体，非翻译腔。

## Keywords
写歌、歌词创作、古诗词改编、古文配乐、歌曲创作、原文化用、叙事歌词、曲风编曲

## Strategy
1. **解析考据**：读原文 + 考作者生平/创作背景（前因）+ 考流传影响（后果）。见 [modules/01-analyze.md](modules/01-analyze.md)
2. **立叙事骨架**：前因（为何而作）→ 本体（说了什么）→ 后果（影响与共鸣），定情感曲线。见 [modules/02-lyrics.md](modules/02-lyrics.md)
3. **用户确认**：骨架与情感基调给用户过目，确认后再作词
4. **作词**：主歌叙事、副歌意象化用、桥段升华。见 [modules/02-lyrics.md](modules/02-lyrics.md)
5. **定曲+描曲**：情感基调 → 曲风/BPM/调式/配器；**以文字描曲**（总纲/逐段六维/唱法总则/动机贯穿）。见 [modules/03-music.md](modules/03-music.md) 与 [modules/05-score.md](modules/05-score.md)
6. **输出**：**词曲一体**——歌词（标化用出处）+ 文字描曲 + 曲风方案 + 原文对照表（教学可用）。见 [modules/04-output.md](modules/04-output.md)

## AVOID
- AVOID 翻译腔——把"床前明月光"写成"床前有明亮的月光"，此乃低级改编，失原作魂魄
- AVOID 只改原文不融背景——前因（为何而作）不可缺，缺则歌词无骨
- AVOID 堆砌典故——用典须转现代意象或口语化，生僻典故入词即隔
- AVOID 照抄他人歌词——范本/现成作品零借用（意象、句子、主题词皆禁）；学其法不学其词
- AVOID 原文直引泛滥——名句直引一首至多 2 处，同句不重复唱（"到客船"说一遍足矣）
- AVOID 副歌无原文基因——副歌必含原文意象之化用或名句之直引，否则与普通情歌无异
- AVOID 词曲脱节——歌词情感基调与曲风/配器须一致，悲词配欢曲乃败笔
- AVOID 考据臆造——作者生平、历史背景须可靠，教学场景尤严，不确定则注"存疑"
- AVOID 不确认直接长篇输出——骨架、基调先短示确认，再作全词
- AVOID 口水直白——"简历投了又投 消息沉进深海里"乃口水；改"投出去的字 沉入深深海底"
- AVOID 流水账叙事——"后来我去过苏州"式时间平推乃流水账；须双线并置、意象叠映（见模块二·深度三法）

## 工作流程

### 阶段 1：定对象
**📖 必读**: [modules/01-analyze.md](modules/01-analyze.md)
- 用户给原文 → 直接用
- 用户只给篇名 → 检索全文（须可靠来源，校核无误）
- 确认：改编对象 + 用途（教学/创作/两者）+ 有无指定曲风

### 阶段 2：解析考据（三读法）
**执行**:
1. 读原文：主题、情感基调、叙事脉络、核心意象与意境
2. 读前因：作者生平节点、创作时代、触发事件（为何而作）
3. 读后果：作品流传、后世评价、今人共鸣点

**输出格式**:
```
📖 解析报告
【原作】《篇名》 作者 年代
【主题】一句话
【情感基调】悲/壮/愁/旷达/思/愤…
【核心意象】意象1、意象2、意象3
【意境】一句（月落霜寒之愁、对酒狂歌之放…）
【前因】为何而作：…
【后果】流传与共鸣：…
```

### 阶段 3：立叙事骨架 + 确认
**📖 必读**: [modules/02-lyrics.md](modules/02-lyrics.md) 之「叙事骨架」
**执行**:
1. 定前因→本体→后果在歌词中的分布
2. 定情感曲线（起→承→转→合）
3. 短示骨架，用户确认后再作词

**输出格式**:
```
🎵 叙事骨架
【前因】→ 主歌1（背景故事，1-2句点破）
【本体】→ 主歌2/预副歌（意象展开）
【后果】→ 桥段（影响与共鸣，今人对望）
【副歌】核心意象化用（情感爆发点）
【情感曲线】起(平静) → 承(渐强) → 转(爆发) → 合(余韵)
```

### 阶段 4：作词
**📖 必读**: [modules/02-lyrics.md](modules/02-lyrics.md) 之「意象化用」与「歌词结构」
**执行**:
1. 按原文运用与化用处理：名句直引点睛（≤2处）、意象化用为血肉
2. 依结构布段：主歌1/预副歌/主歌2/副歌/桥段/尾声
3. 押韵与节奏：依曲风定韵脚密度，口唱顺为要

### 阶段 5：定曲
**📖 必读**: [modules/03-music.md](modules/03-music.md)
**执行**:
1. 情感基调 → 查映射表定曲风
2. 定 BPM、调式（古风用五声，现代可混）、配器、唱法
3. 古风作品：现代编曲 + 民乐点缀，勿纯仿古

### 阶段 6：输出（词曲一体）

**📖 必读**: [modules/04-output.md](modules/04-output.md) 之输出模板 + [modules/05-score.md](modules/05-score.md) 之文字描曲

**输出格式**:
```
🎼 《歌名》—— 改编自《原作》
【词】(分主歌/副歌/桥段，化用句后注来源)
【曲】(文字描曲：总纲五件 + 逐段六维 + 唱法总则 + 动机贯穿)
【曲风方案】(曲风/BPM/调式/配器/情绪线)
【AI音乐工具提示】可粘贴 Suno/ACE 的完整提示
【原文对照表】(歌词句 ↔ 原文出处)  ← 教学必附
```
**输出前检查**:
- [ ] 前因后果皆入词，非只译原文
- [ ] 副歌含原文基因（意象化用或名句直引，≤2处）
- [ ] 无翻译腔，无生僻典
- [ ] 情感基调词曲一致
- [ ] 歌词口唱顺畅，无拗口
- [ ] 对照表标注无误
- [ ] 文字描曲总纲五件齐、逐段六维皆述、动机贯穿、唱法总则成表
