# 模块一：解析与考据（三读法）

## 宗旨

作词前必三读：**读原文、读前因、读后果**。缺一不成歌。
原文是血肉，前因是骨，后果是魂——三样齐，歌词方立得住。

## 一读：原文

| 提取项 | 问什么 | 用于 |
|--------|--------|------|
| 主题 | 这篇在说什么？一句话概括 | 定副歌核心 |
| 情感基调 | 悲/壮/愁/旷达/思/愤/恬淡… | 定曲风 |
| 叙事脉络 | 起承转合在何处 | 定歌词结构 |
| 核心意象 | 酒、月、江、白发、孤舟… | 化用入词（意象/新句） |
| 名句 | 传诵之句、题眼之句（标位置） | 可直引点睛，至多 2 处 |

要点：
- 意象选 3-5 个为限，宁精勿滥；名句标位置备直引（≤2 处）
- 现代散文/小说：名句 = 主题句/金句；意象 = 反复出现之物

## 二读：前因（为何而作）

考作者生平节点 + 创作时代 + 触发事件。

| 渠道 | 可靠度 |
|------|--------|
| 原文自注、序跋 | 最高 |
| 《全唐诗》等总集题解、正史传记 | 高 |
| 权威注本（中华书局/上海古籍） | 高 |
| 网络百科/自媒体 | 低——须交叉验证 |

要点：
- 前因须与歌词叙事直接相关，取 1-2 个关键节点即可，勿堆生平
- 不确定处标"存疑"，教学场景尤严，宁缺毋造
- 例：《将进酒》前因 = 李白赐金放还后，与岑勋、元丹丘会饮于嵩山，怀才不遇而作狂歌

## 三读：后果（影响与共鸣）

作品流传之况、后世评价、今人共鸣点。

要点：
- 后果是桥段素材——今人对望处
- 取 1-2 个共鸣点：为何千百年后仍打动人
- 现代作品：后果 = 作品引发的时代讨论/读者回响

## 输出格式

```
📖 解析报告
【原作】《篇名》 作者 年代
【主题】一句话
【情感基调】悲/壮/愁/旷达…
【核心意象】意象1、意象2、意象3
【名句】句1（位置）、句2（位置）——备直引
【前因】为何而作：…（来源：…，不确定处标存疑）
【后果】流传与共鸣：…
```

## 检查

- [ ] 意象、名句已定位（名句 ≤2 处备直引）
- [ ] 前因有据，非臆造
- [ ] 后果共鸣点已明
