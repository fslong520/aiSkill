# 模块三：曲风编曲方案

## 宗旨

词曲一致：**情感基调定曲风，曲风定 BPM/调式/配器**。
古风作品——现代编曲 + 民乐点缀，勿纯仿古（纯仿古今人听不进）。

## 一、情感基调 → 曲风映射

| 情感基调 | 推荐曲风 | BPM | 调式 |
|----------|----------|-----|------|
| 豪放/悲壮 | 国风摇滚、古风燃曲 | 100-140 | 五声宫/徵调 |
| 旷达/洒脱 | 民谣、国风流行 | 70-100 | 五声羽/宫调 |
| 忧愁/思乡 | 古风抒情、民谣 | 60-85 | 五声羽调 |
| 相思/婉约 | 古风流行、情歌 | 65-85 | 五声羽/商调 |
| 恬淡/归隐 | 民谣、轻国风 | 60-80 | 五声宫/角调 |
| 愤懑/不平 | 摇滚、说唱融合 | 90-120 | 小调为主 |
| 现代散文/小说 | 对应情感选流行/民谣/摇滚，可无古风元素 | — | 大小调皆可 |

注：情感基调有多重时，取主基调定曲，副基调作编曲层次。

## 二、调式要点

- **五声调式**（宫商角徵羽）——古风骨相，现代流行编曲包裹
- 宫调式（1 2 3 5 6）——明亮开阔，配豪放/旷达
- 羽调式（6 1 2 3 5）——柔美抒情，配愁思/婉约
- 转调设计：桥段转调（+1 或 +2 半音）推高潮，落尾声再回

## 三、配器建议

| 层次 | 古风 | 现代散文 |
|------|------|----------|
| 底 | 钢琴/吉他分解和弦 | 按曲风（电子/吉他/钢琴） |
| 骨 | 鼓点（民乐鼓/架子鼓） | 鼓点（对应风格） |
| 肉 | 弦乐铺底、古筝/笛/箫点缀 | 弦乐/合成器 |
| 皮 | 民乐 solo 句（笛/箫/二胡） | 主奏乐器 |

原则：
- 民乐点缀不淹没——一句笛声、一段筝琶即可
- 前奏用原文意象之音（水声/风声）开画面
- 副歌层次最满，主歌留白，桥段可减配器再爆发

## 四、唱法建议

| 基调 | 唱法 |
|------|------|
| 豪放/悲壮 | 胸腔共鸣，副歌高音实唱，可加嘶哑/怒音点缀 |
| 旷达/洒脱 | 松弛自然，说唱段可穿插 |
| 忧愁/思乡 | 气声为主，句尾叹息感 |
| 相思/婉约 | 真假声转换，轻柔 |
| 愤懑/不平 | 低音沉、高音爆，对比强烈 |

## 五、输出格式

```
🎵 曲风方案
【曲风】国风摇滚
【BPM】120
【调式】五声宫调（1 2 3 5 6），桥段转升半音
【配器】钢琴分解起 → 民乐鼓+电吉他入副歌 → 笛声点缀；桥段减配器 → 副歌再现全开
【唱法】主歌松弛叙事，副歌胸腔高音实唱
【情绪线】平静起 → 渐强 → 爆发 → 转调升华 → 余韵收
```
