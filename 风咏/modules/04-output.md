# 模块四：输出格式

## 输出总览

```
🎼 《歌名》—— 改编自《原作》
【一句话】歌是什么
【歌词】分主歌/副歌/桥段，化用句后注来源
【曲风方案】曲风/BPM/调式/配器/唱法/情绪线
【原文对照表】歌词句 ↔ 原文出处（教学必附）
【AI音乐工具提示】可粘贴 Suno/ACE 的完整提示
```

## 一、歌词模板

```
《歌名》

[主歌1]
（前因叙事，画面感）

[预副歌]
（情绪拉升句）

[主歌2]
（本体意象展开）

[副歌]
（核心意象化用——全曲最高点）
（副歌×2 或×3 处标注变化句）

[桥段]
（后果/升华，今人对望）

[尾声]
（留白收束）
```

原文运用标注：
- 名句直引 → `（引《原作》"夜半钟声到客船"）`
- 裁句引子 → `（引"月落乌啼霜满天"续作）`
- 意象化用 → `（化"江枫渔火"——渔家灶火正温）`
- 同句不重复唱（"到客船"说一遍）

## 二、原文对照表（教学必附）

| 歌词句 | 运用 |
|--------|------|
| 月落乌啼霜满天 | 《枫桥夜泊》裁句引子 |
| 姑苏城外寒山寺 / 夜半钟声到客船 | 名句直引（副歌锚点，一遍） |
| 渔家灶火正温 | 《枫桥夜泊》"江枫渔火"意象化用 |

用途：教学场景讲"化用"手法——原文如何变成歌词，学生一目了然。

## 三、AI 音乐工具提示

给 Suno/ACE 等工具的完整提示模板：

```
【风格】{曲风}，{BPM} BPM，{调式}，{唱法描述}
【情绪】{情绪线}
【结构】主歌-预副歌-副歌-主歌-副歌-桥段-副歌-尾声
【歌词】
{歌词全文，含段落标签}
```

要点：
- 曲风描述用工具熟知的标签词（如 "epic chinese rock, male vocal"）
- 歌词保留段落标签 [Verse]/[Chorus] 或中文皆可，视工具而定
- 注明"female/male vocal"与情绪词

## 四、教学附注（教学场景附加）

- 【原作背景】前因简述（考据来源）
- 【化用解析】三式化用各举一例，讲手法
- 【朗读对比】原诗与歌词并置，体会"翻译"与"化用"之别

## 输出前检查

- [ ] 歌词含段落标签，可唱
- [ ] 标注齐全（直引 ≤2 处/意象化用），同句不重复
- [ ] 对照表无误，无张冠李戴
- [ ] 曲风方案与歌词情感一致
- [ ] AI 工具提示可直接粘贴
