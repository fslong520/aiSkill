# 模块五：评估门禁

## 三大功能

### 1. 触发评估

技能创建/修改后，自动运行质量门禁：

- 结构完整性检查（Gene四要素）
- 信号密度计算（>80%为通过）
- Token效率验证（<300 token为优）
- 占位符扫描（`[xxx]`、`TODO`、`待补充`）

### 2. 发布门禁

发布到 ClawHub 前的强制检查：

- metadata.trigger 必须存在
- SKILL.md < 200行
- 必须有示例（examples/ 或内联）
- AVOID >= 3条
- 版本号符合语义化

### 3. 验证器

验证逻辑用Markdown描述，Agent执行检查：

验证项：
- [ ] frontmatter 格式正确
- [ ] Gene 四要素齐全
- [ ] 无占位符
- [ ] 信号密度 > 阈值
- [ ] SKILL.md 行数合规
- [ ] metadata.trigger 存在

## 触发评估流程

1. 读取技能文件（SKILL.md + modules/）
2. 检查结构完整性
3. 计算信号密度
4. 验证Token效率
5. 扫描占位符
6. 输出评估报告

## 发布门禁流程

1. 检查 metadata.trigger
2. 检查 SKILL.md 行数
3. 检查示例存在
4. 检查 AVOID 数量
5. 检查版本号格式
6. 输出门禁报告

## 信号密度计算

```
信号密度 = (有效信息行数 / 总行数) × 100%
```

有效信息行：包含关键词、步骤、表格、列表的行
无效信息行：空行、注释、重复内容

## 占位符扫描

扫描以下模式：
- `[xxx]`、`[请填写]`
- `TODO`、`FIXME`
- `待补充`、`待完善`
- `示例`、`例子`

## 版本号格式

语义化版本：`MAJOR.MINOR.PATCH`

- MAJOR：不兼容的API变更
- MINOR：向下兼容的功能性新增
- PATCH：向下兼容的问题修正

## AVOID

- AVOID 跳过门禁直接发布
- AVOID 忽略占位符扫描
- AVOID 信号密度计算错误
- AVOID 版本号格式不规范
- AVOID 门禁检查不全面
