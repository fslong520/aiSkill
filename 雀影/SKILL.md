## Summary

交互式引导完善视频创意，生成分镜脚本和 Seedance 提示词。

## 创作世界观（麦基核心，一切决策之根）

**故事不是镜头堆砌，是价值转变的链条。** 每个镜头都必须改变一个价值（爱恨/生死/真假/自由奴役）的正负状态——价值不变的镜头就是废镜。导演的全部工作：让观众看见价值如何被一步步推到不可逆的转变点。

- **触发事件**：第一个镜头就要打破主角生活平衡（钩子即触发事件，禁铺垫）
- **对立力量**：张力来自对抗主角欲望的**全部力量之和**（内在/个人/社会/环境四层），非单反派
- **双欲望**：自觉欲望（对白明线："我要赢"）+ 不自觉欲望（内心独白暗线："我需要被认可"）
- **压力下的选择**：角色真相只在他被迫两难时暴露——设计"善vs善"困境
- **鸿沟**：期望落空即反转引擎——观众以为A，世界回应B
- **高潮**：不可逆的价值转变，必须由主角自己的选择促成
- **潜文本**：说的 vs 想的差距 = 张力。对白永不说真心话，真心话交给内心独白

## Strategy

1. 用户描述视频内容 → 确认素材、时长、类型
2. **解剖故事（麦基引擎）**——按 触发事件→对立力量→双欲望→价值曲线（从何价值到何价值）四步立骨架，见[故事结构设计规范](故事结构设计规范.md)
3. 视觉风格：由价值基调决定（正→负 用压抑色调，负→正 用明亮色调）
4. 角色锚点：为每个角色定"压力下的选择"——他会在哪个两难时刻暴露真相
5. 镜头节奏：按价值曲线分配镜头——钩子=触发事件，转捩点=价值转变，高潮=不可逆
6. 台词音效：潜文本（说A想B）+ 内心独白（不自觉欲望揭示器）
7. 确认画面比例 → 生成分镜脚本 → 输出 prompt

AVOID:
- AVOID 不读规范文档就生成，应该先读人物刻画规范、Prompt技术规范、台词与音效规范、故事结构设计规范
- AVOID 不立价值曲线直接写镜头——每个镜头必须标注其改变的价值（正↔负），价值不变的镜头直接删
- AVOID 镜头数量超出范围，5s=3-4镜，10s=5-7镜，15s=7-10镜，30s=12-18镜
- AVOID 武戏全程慢动作/定格——快攻为主，慢放只用于力量巅峰关键帧（speed ramp），见导演思维与节奏规范
- AVOID 画面 prompt 文字超量——每镜 ≤2 句核心，删诗化修饰，AI 平台消化不了长 prompt
- AVOID 台词全部短句无变化，长短结合、冲突递进、潜台词皆有
- AVOID 对白说真心话——自觉欲望走对白，不自觉欲望走内心独白，差距即张力
- AVOID 忘记内心独白——内心独白是短剧推进剧情之核心手段
- AVOID 忘记字幕——每句音频标角色名，首次出场加身份浮标，心声加"（心声）"
- AVOID 对立力量只有单反派——按内在/个人/社会/环境四层次叠加张力
- AVOID 高潮靠巧合或他人解救——高潮必须由主角自己的选择促成且不可逆
- AVOID 忘记尾帧处理，最后0.3秒快速切黑

| 15s | 7-10 |
| 30s | 12-18 |

## 台词规范

- 日常对白：每句 4-12 字，自然口语化
- 情绪爆发：每句 2-6 字，语速快（每秒 5-7 字）
- 内心独白：每句 6-15 字，语速慢（每秒 2-3 字），有呼吸感
- 潜台词：言外有意，话说一半，留白让观众品
- 节奏：对白之间留自然停顿，不可连珠炮无呼吸

## 输出格式

```
（时长 X 秒）【标题】（风格）（色调）

【价值曲线】起点价值 → 转折价值 → 终点价值（不可逆）
【触发事件】平衡被什么打破
【对立力量】内在/个人/社会/环境 各自是什么
【主角欲望】自觉：... ｜ 不自觉：...
【剧情梗概】...
【人物重点】...
【场景重点】...
【字幕】对白显"角色名：台词"、首次出场"角色名·身份"浮标、心声加"（心声）"、旁白无角色名

[镜头 1-首帧] X 秒 景别+运镜 人物描述 动作（场景）
【价值】平衡 → 失衡（触发事件落地）
【角色】秦琼（字幕）："台词" #Xs [音量:XX%]（情绪）
【内心独白】秦琼（心声）"..." #Xs [音量:70-80%]（放慢，带混响）
（音效）音效 #Xs
...
[镜头 N-尾帧] X 秒 ... 最后 0.3 秒快速切黑
【价值】旧秩序 → 新秩序（高潮不可逆，主角促成）
```

> 画面 prompt 每镜 ≤2 句核心（AI 平台容量）；字幕并入音频行，不独立成行。

### 音频三要素（按优先级排列）

| 要素 | 作用 | 字数/时长 |
|------|------|----------|
| 对白 | 角色间交锋、情绪碰撞 | 4-12 字/句 |
| 内心独白 | 角色内心真实想法，观众唯一能听到的心声 | 6-15 字/句 |
| 旁白 | 交代背景、补画面不足、推进剧情 | 8-15 字/句 |

### 音频层次（从近到远）

```
观众耳中 →
  第一层：内心独白（最贴近观众）
  第二层：对白（角色间的交流）
  第三层：旁白（全知视角）
  第四层：环境音（氛围基础）
  第五层：配乐（情绪底色）
  第六层：特效音（动作/转场增强）
```
