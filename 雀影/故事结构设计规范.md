# 故事结构设计规范（麦基《故事的解剖》框架）

> 依据：罗伯特·麦基《Story: Substance, Structure, Style》核心原理。
> 核心信条：**好故事不是靠灵感和运气，而是可以精确掌握的技艺。** 75% 的创作精力应投入故事设计——先搭骨架，再写镜头。

## 一、写分镜前的故事骨架四问

动笔写任何镜头之前，先回答这四问。答不出 = 故事没立起来，镜头再多也是空转。

| # | 问题 | 麦基术语 | 短剧示例 |
|---|------|---------|---------|
| 1 | 哪一刻彻底颠覆了主角生活的平衡？ | 触发事件 | 外卖小哥收到"去死"差评——他决定找出是谁 |
| 2 | 什么力量在对抗主角的欲望？ | 对立力量 | 差评者（个人）+平台规则（社会）+自身自卑（内在） |
| 3 | 主角真正想要什么？表面要什么？ | 自觉欲望 vs 不自觉欲望 | 表面：找出差评者。真正：证明自己配得上被尊重 |
| 4 | 结尾的价值如何不可逆地翻转？ | 高潮 | 他原谅了差评者——从"仇恨"到"释然"，永不再回头 |

---

## 二、触发事件——开场的灵魂

**定义**：彻底颠覆主角生活平衡的事件，唤起主角重建平衡的欲望。

### 设计双问（互为镜像）

| 方向 | 提问 |
|------|------|
| 悲→喜 | 我的主角可能遇到的最糟的事是什么？如何让它转化为最好的事？ |
| 喜→悲 | 我的主角可能遇到的最好的事是什么？如何让它转化为最糟的事？ |

### 短剧落地规则

- **钩子 = 触发事件前置**：短剧没有 30 分钟铺陈，第一个镜头就是触发事件
- 触发事件必须在 1-2 镜内发生（首帧或第二镜），观众来不及走神
- 触发事件后立刻提出"剧情重要疑问"：观众心中自动浮现"接下来会怎样？"
- 反例：开场先放三秒城市空镜 + 旁白背景交代——观众已划走
- 正例：开场直接是"门被踹开，主角抬头，欠条拍在桌上"——疑问即刻产生

## 三、对立力量四层次——张力的叠加

**麦基最重要原则**：对立力量 ≠ 一个反派，而是**对抗主角意志及欲望的所有力量之总和**。人性保守，不做不必要之事——对立越强，角色越完整。

| 层次 | 范围 | 短剧示例 |
|------|------|---------|
| 内在 | 自我（恐惧、愧疚、自卑、成瘾） | 主角不敢开口说话的自卑 |
| 个人 | 家人、伴侣、朋友、对手 | 差评者本人、不理解的妻子 |
| 社会 | 法律、阶层、文化、体制 | 平台差评机制、职场规则 |
| 环境 | 灾难、时间、空间、疾病 | 暴雨夜、倒计时、医院走廊 |

**叠加原则**：层次叠得越多，张力越强。最平淡的短剧 = 只有一个表层对手。
**使用场景**：写完觉得"太平了" → 检查四层次缺了哪层，补上。

---

## 四、人物弧光 = 压力下的选择

人物真相只能通过**压力下的选择**揭示——低压力下说"我是好人"没有意义。

### 两难困境设计

- 必须让角色在**两个不可兼得的价值**间抉择
- 两个选项都有代价（否则不是真选择）
- 最有力的是"善 vs 善"：救母亲还是救爱人？说出真相还是保护家人？

### 自觉欲望 vs 不自觉欲望

| | 自觉欲望 | 不自觉欲望 |
|---|---------|-----------|
| 定义 | 表面追求、自知的目标 | 内心真正需要、不自知的东西 |
| 作用 | 驱动情节线 | 赋予深度 |
| 示例 | "我要赢下这场比赛" | "我需要父亲认可我" |

**短剧落地**：短剧时长有限，不自觉欲望不必明说，用**内心独白**点一次即可（见对白与内心独白设计规范之三层真实原则）。

## 五、鸿沟原理——反转的引擎

**定义**：角色采取行动 → 期望世界作出某种反应 → 世界回应了截然不同的东西 → 落差（鸿沟）迫使角色调整行动，故事由此推进。

短剧的"反转"本质就是鸿沟的兑现：

```
角色行动：主角质问差评者"为什么害我"
期望回应：对方辩解/道歉
实际回应：对方冷笑"因为你不配活着"
→ 鸿沟出现 → 主角的世界认知被打破 → 下一轮行动升级
```

**使用场景**：剧情停滞、观众猜到下一步 → 让角色行动的结果偏离期望，制造鸿沟。

## 六、场景五要素——每镜自检

每写一个镜头，对照五要素。重点检查转捩点与选择。

| 要素 | 检查问题 |
|------|---------|
| 转捩点 | 本镜结尾的价值状态与开头不同吗？（正→负 或 负→正） |
| 铺陈/回馈 | 植入了后续会爆炸的细节吗？（地雷要埋得隐蔽） |
| 情绪动态 | 情绪在本镜中上升还是下降？ |
| 节拍 | 角色的行为有细微变化吗？ |
| 压力下的选择 | 角色被迫作出了有意义的选择吗？ |

**转捩点**是场景的灵魂：价值不变 = 这个镜头可以删。

## 七、微型三幕结构（适配短剧）

短剧是压缩的电影，同样遵循三幕，只是比例极致化：

| 幕 | 短剧占比 | 功能 | 镜头分配（10s 为例） |
|----|---------|------|---------------------|
| 第一幕 | ~15% | 触发事件 + 剧情疑问 | 1-2 镜 |
| 第二幕 | ~60% | 对立升级 + 鸿沟 + 两难 | 3-6 镜 |
| 第三幕 | ~25% | 高潮（不可逆转折）+ 余韵缓冲 | 7-9 镜，尾帧切黑 |

**高潮铁律**：
1. 不可逆——不能是"其实是一场梦"
2. 由主角自己的选择导致——不能是巧合或他人解救
3. 释放故事累积的全部力量
4. 高潮后留 0.3-1 秒缓冲再切黑（对应尾帧处理）

## 八、潜文本——对白的灵魂

**定义**：角色说的话与真正意思之间的差距。差距越大，张力越强。

- 角色说 A，真正意思是 B
- 短剧中对白 + 内心独白天然构成潜文本：对白说表层，内心独白说深层
- 检查：如果删掉内心独白后观众仍能从对白听出潜台词，说明对白"太直白"

```
潜文本示例：
对白："这茶不错。"（她想说：别走）
对白："天快黑了。"（她想说：我再留你会舍不得）
—— 逐句对白都只是冰山一角，真正的情感沉在水下
```

## 九、完整示例：10 秒短剧故事骨架

```
【触发事件】女儿发现父亲偷偷卖掉了外婆留下的老房子（镜头1）
【剧情疑问】父亲为什么要卖？钱去哪了？
【对立力量】内在：女儿不敢质问父亲的愧疚
             个人：父女冷战
             社会：老房子拆迁潮、房产中介施压
【自觉欲望】女儿：要回房子
【不自觉欲望】女儿：想要父亲亲口承认"他其实需要这笔钱治病"
【两难选择】父亲承认卖房是为了治病，但要她发誓不告诉母亲（镜头6）
【高潮】女儿把卖房合同推回去："妈那边，我来说。"（镜头8）
        价值：从"怨恨父亲"不可逆转为"守护父亲"
【余韵】尾帧：父亲低头，手在发抖（镜头9）+ 切黑
```

## 十、检查清单

- [ ] 四问全部答得出？答不出 = 骨架未立，勿写镜头
- [ ] 触发事件在 1-2 镜内发生？
- [ ] 对立力量 ≥ 2 层？（纯单反派 = 扁平）
- [ ] 主角有自觉 + 不自觉双欲望？
- [ ] 至少一处两难选择（善 vs 善 / 恶 vs 恶）？
- [ ] 至少一处鸿沟（期望落空）？
- [ ] 每个镜头有转捩点？价值是否变化？
- [ ] 高潮不可逆、由主角促成、释放全部力量？
- [ ] 潜文本存在？对白不是直白说明书？
